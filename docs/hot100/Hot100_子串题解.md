# Hot100 子串题解

只整理 LeetCode Hot 100 里属于 `子串` 的题。

## 一、子串前置知识：先分清“连续”这件事

这类题最容易卡住的地方，不是公式，而是概念。

先记住：

- `子数组 / 子串`：必须连续
- `子序列`：不用连续，只要相对顺序不乱

Hot100 里的“子串”专题，常见不是考某个单独数据结构，而是考：

- 前缀和
- 哈希统计
- 连续区间怎么快速求值

什么时候该想到这些方法：

- 题目问“连续一段”的和、数量、是否满足条件
- 你发现暴力枚举所有区间会很慢

要特别注意：

- 一旦题目强调“连续”，优先往前缀和、滑动窗口、哈希上想
- 前缀和题要想清楚：`当前前缀和 - 以前某个前缀和 = 目标`
- 不要把“子串”和“子序列”的思路混着用

速记一句话：

`子串题先抓住“连续”，再想怎么把一段区间的信息快速算出来。`

## 560. 和为 K 的子数组


### 题目

原题：[560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

给你一个整数数组 nums 和一个整数 k ，请你统计并返回 该数组中和为 k 的子数组的个数 。

子数组是数组中元素的连续非空序列。

示例 1：

输入：nums = [1,1,1], k = 2
输出：2

示例 2：

输入：nums = [1,2,3], k = 3
输出：2

提示：

- 1 <= nums.length <= 2 * 104

- -1000 <= nums[i] <= 1000

- -107 <= k <= 107

### 思路

前缀和 + 哈希。若 `pre[i] - pre[j] = k`，则 `pre[j] = pre[i] - k`。遍历时统计之前出现过多少个这样的前缀和。

### 口诀

`当前前缀和，去找差值`

### 图解

```text
pre = 当前前缀和
如果以前有 pre-k
说明中间这段和为 k
```

### Python

```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums, k):
        count = defaultdict(int)
        count[0] = 1
        pre = 0
        ans = 0
        for num in nums:
            pre += num
            ans += count[pre - k]
            count[pre] += 1
        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 239. 滑动窗口最大值


### 题目

原题：[239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)

给你一个整数数组 nums，有一个大小为 k 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 k 个数字。滑动窗口每次只向右移动一位。

返回 滑动窗口中的最大值 。

示例 1：

输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
1 [3  -1  -3] 5  3  6  7       3
1  3 [-1  -3  5] 3  6  7       5
1  3  -1 [-3  5  3] 6  7       5
1  3  -1  -3 [5  3  6] 7       6
1  3  -1  -3  5 [3  6  7]      7

示例 2：

输入：nums = [1], k = 1
输出：[1]

提示：

- 1 <= nums.length <= 105

- -104 <= nums[i] <= 104

- 1 <= k <= nums.length

### 思路

用单调队列，队列里下标对应的值从大到小。这样队头永远是窗口最大值。

### 口诀

`队列单调递减，队头就是最大值`

### 图解

```text
新数进来前
把后面比它小的都弹掉
因为它们以后不可能当最大值
```

### Python

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        q = deque()
        res = []
        for i, num in enumerate(nums):
            while q and q[0] <= i - k:
                q.popleft()
            while q and nums[q[-1]] <= num:
                q.pop()
            q.append(i)
            if i >= k - 1:
                res.append(nums[q[0]])
        return res
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(k)`

## 76. 最小覆盖子串


### 题目

原题：[76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)

给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。

示例 1：

输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。

示例 2：

输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。

示例 3:

输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。

提示：

- m == s.length

- n == t.length

- 1 <= m, n <= 105

- s 和 t 由英文字母组成

进阶：你能设计一个在 O(m + n) 时间内解决此问题的算法吗？

### 思路

先右扩把需要的字符凑齐，再左缩尽量缩短。窗口一直维护“是否已经覆盖 t”。

### 口诀

`先凑齐，再收缩`

### 图解

```text
右边扩到够用
左边开始缩
每缩一步都尝试更新最短答案
```

### Python

```python
from collections import Counter

class Solution:
    def minWindow(self, s, t):
        need = Counter(t)
        missing = len(t)
        left = 0
        start = 0
        min_len = float('inf')
        for right, ch in enumerate(s):
            if need[ch] > 0:
                missing -= 1
            need[ch] -= 1
            while missing == 0:
                if right - left + 1 < min_len:
                    min_len = right - left + 1
                    start = left
                need[s[left]] += 1
                if need[s[left]] > 0:
                    missing += 1
                left += 1
        return "" if min_len == float('inf') else s[start:start + min_len]
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(k)`
