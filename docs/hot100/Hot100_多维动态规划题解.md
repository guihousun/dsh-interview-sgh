## 一、多维动态规划预备课

多维动态规划和一维动态规划最大的区别，不是更难，而是：

`原来只记一排，现在要记一整张表。`

### 1. 为什么 dp 会变成一张表？

当一个下标已经不够描述问题时，`dp` 就会从一维变成二维。

最常见的 3 类情况：

- `网格题`：我要描述“走到第几行第几列”
- `两个字符串`：我要描述“看到了第一个串前 i 个字符、第二个串前 j 个字符”
- `区间题`：我要描述“从左边界 i 到右边界 j 这一段”

所以多维 DP 的本质不是花哨，而是：

`问题本来就有两个维度，所以账本也要开成二维。`

### 2. 怎么读 `dp[i][j]`？

第一次学二维 DP，最容易糊的是：

`这一格到底代表什么？`

你可以强迫自己先把 `dp[i][j]` 翻译成人话。

常见翻译方式：

- 在网格题里：`走到格子 (i, j) 时的答案`
- 在双字符串题里：`A 的前 i 个字符` 和 `B 的前 j 个字符` 的答案
- 在区间题里：`从 i 到 j 这一段` 的答案

也就是说，看到 `dp[i][j]`，不要先看公式，先问：

`这一格在记哪一小块问题的答案？`

### 3. 二维 DP 常看哪几格？

二维表里的当前格，通常不是凭空算出来的，而是参考附近几格旧答案。

最常见的来源有：

- `上边`：`dp[i-1][j]`
- `左边`：`dp[i][j-1]`
- `左上角`：`dp[i-1][j-1]`

直觉上可以这样记：

- `上边`：表示少看一行、少走一步、少用一个字符
- `左边`：表示少看一列、少走一步、少用另一个字符
- `左上角`：表示两个维度都各退一步

所以很多二维 DP 题，核心就是：

`这一格要不要看上、左、左上。`

### 4. 边界为什么总是第一行、第一列、对角线？

因为表格边缘没有足够的“前面格子”可以参考，所以这些地方往往要先手填。

常见边界：

- `第一行`
- `第一列`
- `对角线`
- `空串那一行 / 那一列`

口诀：

`先想这一格表示什么，再看参考哪几格，最后补边界`

图解：

```text
      j-1   j
       ↑    ↑
 i-1  左上  上
 i    左   当前
```

第一次学时，不要急着背公式。
先把整张表看成：

`每一格都在记录一个更小范围的问题答案。`

## 62. 不同路径

### 题目

原题：[62. 不同路径](https://leetcode.cn/problems/unique-paths/)

一个机器人位于一个 m x n 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

示例 1：

输入：m = 3, n = 7
输出：28

示例 2：

输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下

示例 3：

输入：m = 7, n = 3
输出：28

示例 4：

输入：m = 3, n = 3
输出：6

提示：

- 1 <= m, n <= 100

- 题目数据保证答案小于等于 2 * 109

### 思路

这题是二维动态规划入门题。

先把题目翻译成人话：

`走到格子 (i, j) 时，一共有多少种走法？`

因为机器人只能向右或者向下走，所以想走到当前格子，只可能来自：

- 上面 `(i-1, j)`
- 左边 `(i, j-1)`

动态规划三件事：

- `状态`：`dp[i][j]` 表示“走到格子 (i, j) 的不同路径数”
- `转移`：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`
- `初始化`：
  - 第一行全是 `1`，因为只能一直往右
  - 第一列全是 `1`，因为只能一直往下

### 口诀

`到当前格子，只看上边和左边`

### 图解

```text
想走到当前格子：

dp[i-1][j]
    ↓
  dp[i][j]
    ↑
dp[i][j-1]

所以:
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

### 背景知识

- 第一行只能一直往右走，所以全是 1
- 第一列只能一直往下走，所以全是 1
- 这题的答案不是“最短路”，而是“走法总数”

### Python

```python
class Solution:
    def uniquePaths(self, m, n):
        # dp[i][j] 表示：走到第 i 行第 j 列这个格子时，一共有多少种走法
        # 先把整张表都填成 1，因为第一行和第一列本来就是 1
        dp = [[1] * n for _ in range(m)]

        for i in range(1, m):
            for j in range(1, n):
                # 到当前格子，只能从上边或左边过来
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

        return dp[m - 1][n - 1]
```

### 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 64. 最小路径和

### 题目

原题：[64. 最小路径和](https://leetcode.cn/problems/minimum-path-sum/)

给定一个包含非负整数的 m x n 网格 grid ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

说明：每次只能向下或者向右移动一步。

示例 1：

输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。

示例 2：

输入：grid = [[1,2,3],[4,5,6]]
输出：12

提示：

- m == grid.length

- n == grid[i].length

- 1 <= m, n <= 200

- 0 <= grid[i][j] <= 200

### 思路

和上题几乎一模一样，只是：

- 上题问“有多少条路”
- 这题问“哪条路代价最小”

所以你还是只需要看两个来源：

- 上面来
- 左边来

只是这次不是做加法计数，而是选一个更便宜的来源。

动态规划三件事：

- `状态`：`dp[i][j]` 表示“走到格子 (i, j) 时，路径和的最小值”
- `转移`：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`
- `初始化`：
  - `dp[0][0] = grid[0][0]`
  - 第一行只能从左边一路走过来
  - 第一列只能从上边一路走下来

### 口诀

`到当前格子，选上边和左边里更便宜的`

### 图解

```text
到当前格子有两条候选路：

从上边来：dp[i-1][j]
从左边来：dp[i][j-1]

谁更小，就选谁
然后再加上当前格子的值 grid[i][j]
```

### 背景知识

- 第一行和第一列要单独初始化
- 因为它们只有一种走法
- 网格题里，“只能从哪几个方向过来”通常就是转移方程的来源

### Python

```python
class Solution:
    def minPathSum(self, grid):
        m = len(grid)
        n = len(grid[0])

        # dp[i][j] 表示：走到格子 (i, j) 时的最小路径和
        dp = [[0] * n for _ in range(m)]

        # 起点只有一种走法，就是站在自己身上
        dp[0][0] = grid[0][0]

        # 第一列只能从上往下走
        for i in range(1, m):
            dp[i][0] = dp[i - 1][0] + grid[i][0]

        # 第一行只能从左往右走
        for j in range(1, n):
            dp[0][j] = dp[0][j - 1] + grid[0][j]

        for i in range(1, m):
            for j in range(1, n):
                # 到当前格子时，选上边和左边中更小的路径和
                dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]

        return dp[m - 1][n - 1]
```

### 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 5. 最长回文子串


### 题目

原题：[5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

给你一个字符串 s，找到 s 中最长的 回文 子串。

示例 1：

输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。

示例 2：

输入：s = "cbbd"
输出："bb"

提示：

- 1 <= s.length <= 1000

- s 仅由数字和英文字母组成

### 简单版思路

这题最容易记的不是 DP，而是“中心扩展法”。

因为回文串一定是围绕某个中心对称的。

中心有两种：

- 一个字符做中心，像 `aba`
- 两个字符中间做中心，像 `abba`

所以做法非常直接：

`把每个位置都当成中心，然后向左右两边扩。`

如果左右字符一样，就继续扩；不一样就停。

### 口诀

`每个位置都当中心，往两边扩`

### 图解

以 `s = "babad"` 为例：

```text
以 a 为中心:
b a b
↑   ↑
左右相同，可以扩

得到 "bab"

再试下一个中心，看看能不能找到更长的
```

### 背景知识

- 这题虽然被分在多维 DP，但中心扩展法更适合记忆
- `expand(left, right)` 表示从中间开始向两边扩
- `left` 和 `right` 可以一样，也可以挨着，这就是奇数回文和偶数回文的区别

### 简单版 Python

```python
class Solution:
    def longestPalindrome(self, s):
        def expand(left, right):
            # 只要没有越界，并且左右字符相等，就继续扩
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1

            # 循环结束时，多扩了一步，所以要回退
            return s[left + 1:right]

        ans = ""

        for i in range(len(s)):
            # 情况 1：把 s[i] 当成单个中心，比如 "aba"
            s1 = expand(i, i)

            # 情况 2：把 i 和 i+1 中间当成中心，比如 "abba"
            s2 = expand(i, i + 1)

            if len(s1) > len(ans):
                ans = s1
            if len(s2) > len(ans):
                ans = s2

        return ans
```

### 简单版复杂度

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`

### 更优版

还有 DP 写法，但更绕。  
如果目标是快速理解和记忆，这题优先背中心扩展法。

## 1143. 最长公共子序列

### 题目

原题：[1143. 最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)

给定两个字符串 text1 和 text2，返回这两个字符串的最长 公共子序列 的长度。如果不存在 公共子序列 ，返回 0 。

一个字符串的 子序列 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

- 例如，"ace" 是 "abcde" 的子序列，但 "aec" 不是 "abcde" 的子序列。

两个字符串的 公共子序列 是这两个字符串所共同拥有的子序列。

示例 1：

输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列是 "ace" ，它的长度为 3 。

示例 2：

输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc" ，它的长度为 3 。

示例 3：

输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0 。

提示：

- 1 <= text1.length, text2.length <= 1000

- text1 和 text2 仅由小写英文字符组成。

### 思路

这题最重要的是把 `dp[i][j]` 读顺。

不要只看符号，要读成一句中文：

`text1 前 i 个字符，和 text2 前 j 个字符，它们的最长公共子序列长度是多少。`

然后只想“最后一个字符怎么处理”：

- 如果两个字符串最后一个字符相同，那它一定可以接到公共子序列末尾
- 如果不同，那当前这两个最后字符不可能同时都要，只能扔掉其中一个，看哪边更优

动态规划三件事：

- `状态`：`dp[i][j]` 表示“text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列长度”
- `转移`：
  - 如果 `text1[i-1] == text2[j-1]`，`dp[i][j] = dp[i-1][j-1] + 1`
  - 否则 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
- `初始化`：第一行和第一列都是 `0`，因为只要有一个字符串是空串，公共子序列长度就是 0

### 口诀

`相同就一起加一，不同就看上边和左边`

### 图解

```text
如果 text1[i-1] == text2[j-1]
说明最后这个字符可以一起留下

      dp[i-1][j-1]
            ↘ +1
             dp[i][j]

如果不相等:
就只能二选一：

1. 不看 text1 的最后一个字符 -> dp[i-1][j]
2. 不看 text2 的最后一个字符 -> dp[i][j-1]

两者取更大
```

### 背景知识

- “子序列”不要求连续
- 但顺序必须一致
- 这题和“子串”不同，子串要求连续，子序列不要求连续

### Python

```python
class Solution:
    def longestCommonSubsequence(self, text1, text2):
        m = len(text1)
        n = len(text2)

        # dp[i][j] 表示：
        # text1 前 i 个字符 和 text2 前 j 个字符 的最长公共子序列长度
        # 多开一行一列，是为了更方便处理空串边界
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                # 注意这里是 i-1 和 j-1
                # 因为 dp 用的是“前 i 个字符”的定义，比真实下标大 1
                if text1[i - 1] == text2[j - 1]:
                    # 最后一个字符相同，可以一起接上
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 最后一个字符不同，只能舍弃其中一个，选更优结果
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[m][n]
```

### 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 72. 编辑距离

### 题目

原题：[72. 编辑距离](https://leetcode.cn/problems/edit-distance/)

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数 。

你可以对一个单词进行如下三种操作：

- 插入一个字符

- 删除一个字符

- 替换一个字符

示例 1：

输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')

示例 2：

输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')

提示：

- 0 <= word1.length, word2.length <= 500

- word1 和 word2 由小写英文字母组成

### 思路

这题小白最容易卡住的地方，是不知道二维表里每一格到底是什么意思。

这里一定要读成一句完整的话：

`dp[i][j]` 表示：把 word1 的前 i 个字符，变成 word2 的前 j 个字符，最少要几步。

允许的操作只有 3 种：

- `插入`
- `删除`
- `替换`

接着只想最后一个字符：

- 如果最后一个字符本来就一样，那这一位不用动，直接继承左上角答案
- 如果不一样，就分别试：
  - 删掉 `word1` 最后一个字符
  - 在 `word1` 末尾插入一个字符
  - 把 `word1` 最后一个字符替换掉

动态规划三件事：

- `状态`：`dp[i][j]` 表示“word1 前 i 个字符变成 word2 前 j 个字符的最少操作数”
- `转移`：
  - 如果最后字符相同：`dp[i][j] = dp[i-1][j-1]`
  - 否则：在删、插、改三种方案里取最小
- `初始化`：
  - `dp[0][j] = j`，空串变成长度为 `j` 的串，只能一直插入
  - `dp[i][0] = i`，长度为 `i` 的串变成空串，只能一直删除

### 口诀

`字符相同直接继承，字符不同就在增删改里取最小`

### 图解

```text
dp[i][j] 来自三种可能:

1. 删除 word1 的最后一个字符
dp[i-1][j] + 1

2. 在 word1 末尾插入一个字符
dp[i][j-1] + 1

3. 把 word1 的最后一个字符替换掉
dp[i-1][j-1] + 1
```

### 背景知识

- `dp[0][j] = j`：空串变成长度为 `j` 的串，需要插入 `j` 次
- `dp[i][0] = i`：长度为 `i` 的串变成空串，需要删除 `i` 次
- 这题里的 “左、上、左上” 三个方向，分别对应插入、删除、替换

### Python

```python
class Solution:
    def minDistance(self, word1, word2):
        m = len(word1)
        n = len(word2)

        # dp[i][j] 表示：
        # 把 word1 前 i 个字符 变成 word2 前 j 个字符，最少要几步
        dp = [[0] * (n + 1) for _ in range(m + 1)]

        # word1 前 i 个字符变成空串，只能一直删
        for i in range(m + 1):
            dp[i][0] = i

        # 空串变成 word2 前 j 个字符，只能一直插
        for j in range(n + 1):
            dp[0][j] = j

        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i - 1] == word2[j - 1]:
                    # 最后一个字符相同，这一位不用新操作
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    # 三种操作里选代价最小的：
                    # 1. 删除
                    # 2. 插入
                    # 3. 替换
                    dp[i][j] = min(
                        dp[i - 1][j] + 1,      # 删除
                        dp[i][j - 1] + 1,      # 插入
                        dp[i - 1][j - 1] + 1   # 替换
                    )

        return dp[m][n]
```

### 复杂度

- 时间复杂度：`O(mn)`
- 空间复杂度：`O(mn)`

## 三、最后的背诵总结
