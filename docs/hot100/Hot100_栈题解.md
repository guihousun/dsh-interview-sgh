# Hot100 栈题解

核心：`栈就是“后进先出”的盒子，最适合处理最近还没解决的问题。`

## 栈预备课

### 1. 什么是栈

栈（stack）可以理解成一个“后进先出”的盒子。

英文常写成：

`LIFO = Last In, First Out`

意思就是：

`最后放进去的，最先拿出来。`

比如一摞盘子，最上面的盘子通常最先被拿走。  
这就是栈最核心的规律。

### 2. 栈最常见的操作

很多新手一看到栈就只记操作：

- `append()`
- `pop()`

它们在 Python 里通常表示：

- `append(x)`：把 `x` 放到栈顶
- `pop()`：把栈顶元素拿出来

有时还会有：

- `stack[-1]`：看一下栈顶是谁，但先不弹出

### 3. 栈到底适合什么问题

但真正更重要的是先看出：

`有没有一种“最后放进去的东西，要最先拿出来处理”的关系。`

这类题常见在：

- 括号配对
- 撤销 / 回退
- 等待下一个更大 / 更小值
- 先遇到左边界，等右边界出现后再结算

### 4. 为什么括号题很适合栈

括号题的关键是：

`最近打开的左括号，必须最先被关闭。`

这刚好就是“后开先关”，本质上和栈的“后进先出”完全一致。

所以做括号匹配时，常见做法就是：

- 遇到左括号，先压栈
- 遇到右括号，就去匹配栈顶最近的左括号

### 5. 什么是单调栈

单调栈本质上还是栈，只不过栈里元素会保持一种顺序。

常见的有：

- 单调递增栈
- 单调递减栈

它特别适合处理：

- 左边 / 右边第一个更大元素
- 左边 / 右边第一个更小元素

比如每日温度这类题，我们把“还没找到更高温度的那些天”先压着，等后面更高温度出现时，再统一结算它们。

你可以先把单调栈理解成：

`让一批还没拿到答案的人，按顺序在栈里排队等结算。`

### 6. 栈和队列的区别

- 栈：后进先出
- 队列：先进先出

这个区别很基础，但很重要。  
因为很多同学会把“图里的 BFS 队列”和“栈”混在一起。

一句话区分：

- 栈像一摞书，只能先拿最上面的
- 队列像排队，先来的人先走

### 7. 本专题先记住什么

小白先记住这几句：

- `栈 = 后进先出`
- `括号匹配，优先想栈`
- `最近一个还没处理完的东西，通常就在栈顶`
- `找下一个更大 / 更小元素，优先想单调栈`

## 20. 有效的括号


### 题目

原题：[20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

- 左括号必须用相同类型的右括号闭合。

- 左括号必须以正确的顺序闭合。

- 每个右括号都有一个对应的相同类型的左括号。

示例 1：

输入：s = "()"

输出：true

示例 2：

输入：s = "()[]{}"

输出：true

示例 3：

输入：s = "(]"

输出：false

示例 4：

输入：s = "([])"

输出：true

示例 5：

输入：s = "([)]"

输出：false

提示：

- 1 <= s.length <= 104

- s 仅由括号 '()[]{}' 组成

### 思路

这题最适合先用“叠盘子”来理解。

如果你先放进去一个左括号 `(`，又放进去一个左括号 `[`，
那你最先能匹配的，肯定是最后进去的这个 `[`。

所以括号匹配的顺序天然就是：

`后开的，先关。`

这正是栈的特点：

`最后进去的元素，最先出来。`

因此做法很自然：

- 遇到左括号，就先存起来，等以后匹配
- 遇到右括号，就必须去和“最近那个还没匹配的左括号”配对

这个“最近那个还没匹配的左括号”，就是栈顶。

### 口诀

`左括号先存，右括号配最近的左括号`

### 图解

```text
s = "([])"

读到 '(':
stack = ['(']

读到 '[':
stack = ['(', '[']

读到 ']':
要匹配最近的左括号 '['，可以，弹出
stack = ['(']

读到 ')':
要匹配最近的左括号 '('，可以，弹出
stack = []

最后栈空，说明全部匹配成功。
```

### 一步一步怎么做

1. 准备一个栈
2. 遇到左括号就压栈
3. 遇到右括号就检查：
   - 栈是不是空
   - 栈顶是不是对应的左括号
4. 只要有一次对不上，立刻返回 `False`
5. 最后如果栈空，说明全部都匹配完了

### 背景知识

- `stack[-1]`：取列表最后一个元素，也就是栈顶
- `append()`：入栈
- `pop()`：弹出栈顶
- `dict`：这里用来保存“右括号对应哪个左括号”

### Python

```python
class Solution:
    def isValid(self, s):
        # mp 的作用是：
        # 遇到右括号时，可以立刻知道它应该匹配哪个左括号
        mp = {
            ')': '(',
            ']': '[',
            '}': '{'
        }

        # stack 里专门存“还没被匹配掉的左括号”
        stack = []

        for ch in s:
            # 如果是左括号，就先放进栈里
            if ch in '([{':
                stack.append(ch)
            else:
                # 如果是右括号，先看栈有没有东西
                # 没有的话，说明它找不到左括号来配
                if not stack:
                    return False

                # 再看栈顶是不是它应该匹配的左括号
                if stack[-1] != mp[ch]:
                    return False

                # 配对成功，就把这个左括号弹出
                stack.pop()

        # 最后必须栈为空，才说明没有多余的左括号残留
        return len(stack) == 0
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 155. 最小栈


### 题目

原题：[155. 最小栈](https://leetcode.cn/problems/min-stack/)

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

- MinStack() 初始化堆栈对象。

- void push(int val) 将元素val推入堆栈。

- void pop() 删除堆栈顶部的元素。

- int top() 获取堆栈顶部的元素。

- int getMin() 获取堆栈中的最小元素。

示例 1:

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   --> 返回 -3.
minStack.pop();
minStack.top();      --> 返回 0.
minStack.getMin();   --> 返回 -2.

提示：

- -231 <= val <= 231 - 1

- pop、top 和 getMin 操作总是在 非空栈 上调用

- push, pop, top, and getMin最多被调用 3 * 104 次

### 思路

这题的坑点是：

`普通栈只能很快拿到栈顶，不能很快知道最小值。`

如果你每次 `getMin()` 都把整个栈重新扫一遍，时间就是 `O(n)`，不满足题意。

所以要额外准备一个“辅助栈”，专门记录：

`走到当前这一步时，最小值是谁。`

比如依次压入：

- `-2`
- `0`
- `-3`

那么：

- 普通栈：`[-2, 0, -3]`
- 最小栈：`[-2, -2, -3]`

最小栈每一层存的是：

`到当前位置为止的最小值`

这样栈顶一看就知道当前最小值。

### 口诀

`一个栈放数据，一个栈同步放“到当前为止的最小值”`

### 图解

```text
push(-2)
stack     = [-2]
min_stack = [-2]

push(0)
stack     = [-2, 0]
min_stack = [-2, -2]

push(-3)
stack     = [-2, 0, -3]
min_stack = [-2, -2, -3]

所以 getMin() 直接看 min_stack 的栈顶就行。
```

### 一步一步怎么做

`push(val)` 时：

1. 把 `val` 放进普通栈
2. 看辅助栈当前栈顶最小值是多少
3. 把 `min(val, 当前最小值)` 压进辅助栈

`pop()` 时：

- 两个栈一起弹出

因为它们每一层是一一对应的。

### 背景知识

- 这里不是只在出现更小值时才压入辅助栈，而是每次都压
- 这样好处是：两个栈长度永远一样，`pop()` 时最省事

### Python

```python
class MinStack:
    def __init__(self):
        # stack 存真正的数据
        self.stack = []

        # min_stack 的每个位置都记录：
        # “到当前这一层为止的最小值”
        self.min_stack = []

    def push(self, val):
        # 普通栈正常压入
        self.stack.append(val)

        # 如果这是第一个元素
        # 那当前最小值就是它自己
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            # 否则，把“当前值”和“之前最小值”比较
            # 把更小的那个也压入辅助栈
            current_min = min(val, self.min_stack[-1])
            self.min_stack.append(current_min)

    def pop(self):
        # 两个栈必须一起弹
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        # 普通栈栈顶就是真实的顶部元素
        return self.stack[-1]

    def getMin(self):
        # 辅助栈栈顶就是当前最小值
        return self.min_stack[-1]
```

### 复杂度

- 每次操作时间复杂度：`O(1)`
- 空间复杂度：`O(n)`

## 394. 字符串解码


### 题目

原题：[394. 字符串解码](https://leetcode.cn/problems/decode-string/)

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: k[encoded_string]，表示其中方括号内部的 encoded_string 正好重复 k 次。注意 k 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 k ，例如不会出现像 3a 或 2[4] 的输入。

测试用例保证输出的长度不会超过 105。

示例 1：

输入：s = "3[a]2[bc]"
输出："aaabcbc"

示例 2：

输入：s = "3[a2[c]]"
输出："accaccacc"

示例 3：

输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"

示例 4：

输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"

提示：

- 1 <= s.length <= 30

- s 由小写英文字母、数字和方括号 '[]' 组成

- s 保证是一个 有效 的输入。

- s 中所有整数的取值范围为 [1, 300]

### 思路

这题最容易卡住的地方是嵌套，比如：

`3[a2[c]]`

如果第一次看不懂，先不要急着想“栈”这个词。

先把题目翻译成人话：

- `3[a]` 的意思是：把 `a` 重复 3 次，得到 `aaa`
- `2[bc]` 的意思是：把 `bc` 重复 2 次，得到 `bcbc`

真正难的是这种嵌套：

`3[a2[c]]`

为什么它难？

因为你读到外层 `3[` 的时候，只知道：

- 后面有一段内容要重复 3 次
- 但这段内容到底是什么，你还没读完

所以外层现在还不能立刻算出答案。

你只能先把“外层目前的信息”存起来，等最里面那层先算完，再回来继续拼。

这正是栈适合做的事。

一句话理解：

`遇到 '[' 就先存档，遇到 ']' 就把这一层展开`

### 口诀

`左括号先存档，右括号再展开`

### 图解

```text
s = "3[a2[c]]"

先只看最里面：
2[c] -> "cc"

所以原式就变成：
3[acc]

再看外面：
3[acc] -> "accaccacc"

最终答案：
accaccacc
```

### 一步一步怎么做

我们先维护两个“当前状态”：

- `cur_num`：当前正在读的重复次数
- `cur_str`：当前这一层已经拼出来的字符串

遍历字符串时：

- 遇到数字：更新 `cur_num`
- 遇到 `[`：把当前的 `(cur_str, cur_num)` 存进栈
- 遇到 `]`：把上一层弹出来，做展开
- 遇到普通字母：直接拼到 `cur_str` 后面

如果还是抽象，就按字符走一遍：

---

#### 例子：`s = "3[a2[c]]"`

开始时：

```text
stack = []
cur_num = 0
cur_str = ""
```

#### 第 1 步：读到 `'3'`

这是数字，表示后面有一段内容要重复 3 次。

```text
cur_num = 3
cur_str = ""
stack = []
```

#### 第 2 步：读到 `'['`

说明要进入新的一层。

这时先把外层信息存起来：

- 之前已经拼好的字符串是 `""`
- 当前重复次数是 `3`

所以：

```text
stack = [("", 3)]
```

然后开始计算括号里面这一层：

```text
cur_num = 0
cur_str = ""
```

#### 第 3 步：读到 `'a'`

普通字母，直接拼到当前字符串后面：

```text
cur_str = "a"
```

#### 第 4 步：读到 `'2'`

又来了一个重复次数：

```text
cur_num = 2
cur_str = "a"
```

#### 第 5 步：读到 `'['`

又进入更里面的一层。

所以再次存档：

- 当前已经拼好的字符串是 `"a"`
- 当前重复次数是 `2`

```text
stack = [("", 3), ("a", 2)]
```

然后重新开始算最里面这一层：

```text
cur_num = 0
cur_str = ""
```

#### 第 6 步：读到 `'c'`

普通字母，直接拼：

```text
cur_str = "c"
```

#### 第 7 步：读到 `']'`

说明最里面这层结束了。

从栈顶取回上一层的信息：

```text
prev_str = "a"
num = 2
```

当前层字符串是：

```text
cur_str = "c"
```

展开后得到：

```text
"a" + 2 * "c" = "acc"
```

所以现在：

```text
cur_str = "acc"
stack = [("", 3)]
```

#### 第 8 步：读到最后一个 `']'`

说明外层这一段也结束了。

再次从栈里取回上一层信息：

```text
prev_str = ""
num = 3
```

当前层字符串是：

```text
cur_str = "acc"
```

展开后得到：

```text
"" + 3 * "acc" = "accaccacc"
```

所以最终答案就是：

```text
accaccacc
```

### 背景知识

- `isdigit()`：判断字符是不是数字
- `stack.append((a, b))`：把一个二元组放进栈里
- 这里存的是“进入下一层之前的上下文”

### Python

```python
class Solution:
    def decodeString(self, s):
        # 栈里存的是：
        # (进入这一层之前已经拼好的字符串, 这一层需要重复的次数)
        stack = []

        # 当前正在处理的重复次数
        cur_num = 0

        # 当前这一层已经拼好的字符串
        cur_str = ""

        for ch in s:
            if ch.isdigit():
                # 处理多位数，比如 "12[a]"
                cur_num = cur_num * 10 + int(ch)

            elif ch == '[':
                # 遇到左括号，说明要进入更内层
                # 先把当前进度存起来
                stack.append((cur_str, cur_num))

                # 开始重新计算内层内容
                cur_str = ""
                cur_num = 0

            elif ch == ']':
                # 内层已经算完了
                # 把上一层的进度拿回来
                prev_str, num = stack.pop()

                # 当前层展开 num 次，再接到上一层后面
                cur_str = prev_str + num * cur_str

            else:
                # 普通字母，直接接到当前字符串后面
                cur_str += ch

        return cur_str
```

### 复杂度

- 时间复杂度：`O(n)` 到 `O(结果长度)`，核心取决于拼接后的总字符数
- 空间复杂度：`O(n)`

## 739. 每日温度


### 题目

原题：[739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)

给定一个整数数组 temperatures ，表示每天的温度，返回一个数组 answer ，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 0 来代替。

示例 1:

输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]

示例 2:

输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]

示例 3:

输入: temperatures = [30,60,90]
输出: [1,1,0]

提示：

- 1 <= temperatures.length <= 105

- 30 <= temperatures[i] <= 100

### 思路

题目问的是：

`对每一天来说，后面第一个比它高的温度在哪。`

如果暴力做，就是每一天都往后找，最坏会很慢。

真正适合栈的地方在于：

`有些天还没找到更高温度，我们先把它们存起来，等未来某一天来“结算”。`

所以栈里放的不是温度值本身，而是：

`那些还没找到答案的下标`

为什么放下标？

因为最后答案要求的是“几天后”，必须用位置相减。

而且栈要保持一种顺序：

`从栈底到栈顶，对应的温度越来越低`

这样一旦今天温度更高，就能连续帮前面一些更低温度的天数结算答案。

### 口诀

`栈里存还没找到更高温度的下标`

### 图解

```text
temperatures = [73, 74, 75, 71, 69, 72]

读到 73：
stack = [0]

读到 74：
74 > 73，所以第 0 天答案确定为 1
stack = [1]

读到 75：
75 > 74，所以第 1 天答案确定为 1
stack = [2]

读到 71：
71 不比 75 高，先存着
stack = [2, 3]

读到 72：
72 > 71，所以第 3 天答案确定为 1
72 不比 75 高，所以停
stack = [2, 5]
```

### 一步一步怎么做

1. 准备答案数组，初始全是 `0`
2. 准备一个栈，里面放下标
3. 从左到右遍历温度
4. 如果当前温度比栈顶那天温度更高
   - 说明栈顶那天的答案终于找到了
   - 立刻弹出并结算
5. 结算完后，把今天也压进栈

最后还留在栈里的那些天，说明后面再也没有更高温度，所以答案保持 `0`。

### 背景知识

- 这种栈叫“单调栈”
- 这里保持的是“对应温度单调递减”
- `enumerate(temperatures)` 会同时拿到下标和值

### Python

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)

        # 默认答案先都填 0
        ans = [0] * n

        # 栈里存“还没找到更高温度的那些天的下标”
        stack = []

        for i, t in enumerate(temperatures):
            # 只要今天比栈顶那天更热
            # 就说明栈顶那天终于找到答案了
            while stack and temperatures[stack[-1]] < t:
                j = stack.pop()
                ans[j] = i - j

            # 今天暂时还没确定以后会不会有更高温度
            # 先把它的下标放进栈里
            stack.append(i)

        return ans
```

### 复杂度

- 时间复杂度：`O(n)`，每个下标最多进栈出栈各一次
- 空间复杂度：`O(n)`

## 84. 柱状图中最大的矩形


### 题目

原题：[84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)

给定 n 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

示例 1:

输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10

示例 2：

输入： heights = [2,4]
输出： 4

提示：

- 1 <= heights.length <=105

- 0 <= heights[i] <= 104

### 思路

这题最难的不是面积公式，而是：

`以某根柱子为高度时，它到底能向左右扩多宽？`

比如高度是 `5` 的柱子，面积不一定只算它自己宽度 `1`。
如果它左边右边都至少有 `5` 那么高，它就可以扩成更宽的矩形。

关键问题变成：

`什么时候一根柱子的左右边界才算真正确定？`

答案是：

`当你第一次遇到一根比它矮的柱子时。`

因为只要没遇到更矮柱子，它就还可能继续往右扩。

所以我们用单调栈维护“高度递增的柱子下标”。

一旦当前柱子更矮，就说明：

- 栈顶那根更高的柱子，右边界确定了
- 现在就可以结算它的最大面积

### 口诀

`遇到更矮的柱子，就帮更高的柱子结算面积`

### 图解

```text
heights = [2, 1, 5, 6, 2, 3]

当读到高度 2 时：
前面的 6 被挡住了，右边界确定
前面的 5 也被挡住了，右边界确定

所以会先后弹出 6 和 5，并结算面积。

核心不是“当前柱子面积多大”
而是“当前柱子让谁的面积终于可以确定了”
```

### 一步一步怎么做

1. 栈里存下标，保证对应高度递增
2. 当前柱子如果更高，就先入栈
3. 当前柱子如果更矮，就不断弹出比它高的柱子
4. 每弹出一根柱子，就把它当作矩形高度来算面积
5. 宽度由“它左边第一个更矮的柱子”和“它右边第一个更矮的柱子”共同决定

代码里经常会在数组前后补两个 `0`，作用是：

- 前面的 `0` 保证左边一定有界
- 后面的 `0` 保证最后所有柱子都会被弹出来结算

### 背景知识

- 这也是单调栈
- 栈里存的是下标，不是高度值
- 因为后面算宽度时要用位置相减

### Python

```python
class Solution:
    def largestRectangleArea(self, heights):
        # 在左右各补一个 0，方便统一处理边界
        heights = [0] + heights + [0]

        # 栈里存下标，保持对应高度递增
        stack = []

        ans = 0

        for i, h in enumerate(heights):
            # 如果当前高度比栈顶那根柱子更矮
            # 说明栈顶柱子的右边界已经确定了
            while stack and heights[stack[-1]] > h:
                cur = stack.pop()

                # 弹出后，新的栈顶就是“左边第一个更矮的柱子”
                left = stack[-1]

                # i 是“右边第一个更矮的柱子”
                right = i

                # 中间这一段都至少和 heights[cur] 一样高
                width = right - left - 1

                area = heights[cur] * width
                ans = max(ans, area)

            # 当前柱子先入栈，等待以后被结算
            stack.append(i)

        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
