# 力扣教学内容复用

同一道题不应因重新建立练习而反复生成引导与完整讲解。教学内容持久保存在 `leetcode_learning_cache`，不随练习删除；展开/收起、解锁提示和读取答案不会请求 AI。

| 内容 | 复用范围 | 保存位置 |
| --- | --- | --- |
| 题面与 Python 参考代码 | 直接读取本地题解库 | 原有题解表 |
| AI 引导 | 同题、同代码语言、同引导模式 | 题库缓存 |
| 通用 AI 讲解 | 同题、同代码语言，可跨引导模式 | 题库缓存 |
| 本次作答的点评与个人修正版 | 仅本次作答/练习 | 原有练习记录 |
| 提示解锁进度 | 每次练习分别记录，从零开始 | 原有题目记录 |

正常情况下只在内容缺失时生成一次。没有定期失效时间：题面、参考解法或教学规则版本变化才使缓存失效；抓取时间改变不会导致重生成。用户可以明确点击“重新生成 AI 引导/讲解”更新缓存，旧练习读取时也会获得新版内容，保留各自解锁进度。Python 本地参考题解可直接查看，“生成 AI 详解并保存”是可选的进一步讲解。

生成请求按缓存键在 SQLite 中预留，重复点击、同时打开多个面板、不同练习和服务重启共用同一个请求。超时/投递失败显示错误，必须手动重试；已完成内容仍可读取。请求 ID 随保存传回，旧请求结果不能覆盖新请求；缓存与生成内容通过同一个事务提交。

代码点评只分析当前提交，已有参考答案时不再重复生成整题讲解。没有对应语言的通用题解时，首次代码分析可同时保存通用讲解；后续分析复用它，个人反馈仍针对具体 attempt。另一请求已在生成讲解时，只保存本次点评并等待复用结果。

旧档案自动回收无作答且符合提示级数的 AI 引导，以及无作答且代码注释合格的讲解。明确标成 `scope=reference` 的新讲解也可复用；`scope=attempt` 的个人修正版不进入缓存。旧档案回收后的版本来源保存在缓存表，资料变化后不会把旧内容重新标成新版本。

本次本地部署已回收 7 份引导。迁移时对历史题目材料、解锁进度、作答和会话绑定逐项比对，保持一致；升级前保存了 SQLite 快照。

验证：`npm run verify` 共 215 项测试通过，覆盖跨练习复用、语言/模式隔离、刷新和重启、多个数据库连接去重、失败保留、迟到结果回滚、旧内容失效、缓存更新同步、个人点评隔离、对话材料卡复用及界面读写行为。

实现入口：`src/application/leetcode-learning-cache.js`、`src/domain/learning-cache.js`、`src/infrastructure/sqlite-interview-repository.js`；缓存版本由 `LEARNING_CACHE_VERSION` 控制。

## 考场四步引导（2026-10-08）

引导模式依次完成拆解题目与基础知识、理清思路、完整伪代码、带注释的真实代码。解锁进度保存在原有 hintLevel；代码只在第 4 步主动解锁后返回学习视图，不自动作答或评分。基础知识随第 1 步展示，各步可折叠。

仅 guided 引导使用 GUIDED_LEARNING_VERSION=2 的缓存键；standard 提示和 solution 讲解继续沿用原有版本。旧四级提示缺少伪代码或完整实现时不能被回收到新缓存，历史材料保留，首次按新流程生成后继续跨练习复用。生成接口拒绝缺失伪代码、提前给真实代码、语言不一致和无基本注释的实现。
