## 一、先记住贪心的总套路

贪心的核心是：

- 每一步都选“当前看起来最好的选择”
- 不回头改之前的决定

什么时候适合贪心？

- 题目问：最少步数、能不能到、最大收益、最多区间、最优划分
- 并且你能找到一个“局部最优规则”

贪心口诀：

`每一步先顾眼前，只要这个规则始终正确，就能得到全局最优`

图解：

```text
起点 -> 做当前最优选择 -> 继续往前 -> 再做当前最优选择 -> 直到结束
```

### 贪心前置知识：什么叫“当前先这样选”

很多人第一次学贪心，会误会成：

- “看起来顺手就这么写”
- “反正先选大的 / 先选小的”

这都不够准确。

贪心真正的意思是：

- 你找到一条局部规则
- 每一步都按这条规则选
- 并且这条规则不会把最终答案选坏

什么时候该想到贪心：

- 题目问最少步数、最多能选多少个、能不能走到终点、怎么划分最合理
- 你发现不需要把所有历史方案都记下来，只要当前决定正确就能继续

要特别注意：

- 贪心不是“拍脑袋选一个”，而是要有明确规则
- 如果你总担心“现在这么选以后会不会后悔”，那题目可能更像 DP
- 很多贪心题的关键不是写代码，而是先找出“为什么该动这一边 / 选这个区间 / 在这里切一刀”

速记一句话：

`贪心先找规则，再按规则一直走，不回头。`

## 121. 买卖股票的最佳时机

### 题目

原题：[121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

示例 1：

输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2：

输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。

提示：

- 1 <= prices.length <= 105

- 0 <= prices[i] <= 104

### 思路

只能买一次、卖一次。

所以关键是：

- 一边遍历价格
- 一边记录“到当前位置为止最便宜的买入价”
- 当前价格减去历史最低价，就是如果今天卖出能赚多少钱

### 口诀

`一边走，一边记最低买入价`

### 图解

以 `prices = [7,1,5,3,6,4]` 为例：

```text
价格: 7  1  5  3  6  4

走到 7:
最低价 = 7
最大利润 = 0

走到 1:
最低价 = 1
最大利润 = 0

走到 5:
如果今天卖出，利润 = 5 - 1 = 4
最大利润 = 4

走到 6:
如果今天卖出，利润 = 6 - 1 = 5
最大利润 = 5
```

### 背景知识

- `min_price` 表示遍历到当前位置之前的最低价格
- `max_profit` 表示当前找到的最大利润
- 如果后面价格一直更低，利润就一直是 0

### Python

```python
class Solution:
    def maxProfit(self, prices):
        min_price = float("inf")  # 先设成很大，后面不断更新更小值
        max_profit = 0

        for price in prices:
            # 先更新目前见过的最低价
            if price < min_price:
                min_price = price

            # 如果今天卖出，能赚多少钱
            profit = price - min_price

            if profit > max_profit:
                max_profit = profit

        return max_profit
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 更优版

这题上面这个版本就是最优版，也最容易记。

## 55. 跳跃游戏

### 题目

原题：[55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)

给你一个非负整数数组 nums ，你最初位于数组的 第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。

示例 2：

输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0 ， 所以永远不可能到达最后一个下标。

提示：

- 1 <= nums.length <= 104

- 0 <= nums[i] <= 105

### 思路

题目问的是：

- 能不能跳到最后

贪心想法：

- 维护“当前最远能跳到哪里”
- 只要当前位置 `i` 没有超过这个最远范围，说明还能走到这里
- 然后更新最远范围

如果某一刻 `i` 已经超过最远范围，说明断掉了，不能到达。

### 口诀

`一路维护最远可达位置`

### 图解

以 `nums = [2,3,1,1,4]` 为例：

```text
下标: 0 1 2 3 4
数值: 2 3 1 1 4

开始:
farthest = 0

到下标 0:
最远能到 0 + 2 = 2
farthest = 2

到下标 1:
因为 1 <= 2，说明能到这里
最远能到 1 + 3 = 4
farthest = 4

已经能到最后
```

### 背景知识

- `farthest` 表示目前为止最远能到达的下标
- `max(a, b)` 返回更大的值

### Python

```python
class Solution:
    def canJump(self, nums):
        farthest = 0

        for i in range(len(nums)):
            # 如果当前位置已经超过最远可达范围，说明断掉了
            if i > farthest:
                return False

            # 更新最远可达位置
            farthest = max(farthest, i + nums[i])

        return True
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 更优版

这个版本就是最优版。

## 45. 跳跃游戏 II

### 题目

原题：[45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)

给定一个长度为 n 的 0 索引整数数组 nums。初始位置在下标 0。

每个元素 nums[i] 表示从索引 i 向后跳转的最大长度。换句话说，如果你在索引 i 处，你可以跳转到任意 (i + j) 处：

- 0 <= j <= nums[i] 且

- i + j < n

返回到达 n - 1 的最小跳跃次数。测试用例保证可以到达 n - 1。

示例 1:

输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到最后一个位置的最小跳跃数是 2。
从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。

示例 2:

输入: nums = [2,3,0,1,4]
输出: 2

提示:

- 1 <= nums.length <= 104

- 0 <= nums[i] <= 1000

- 题目保证可以到达 n - 1

### 思路

这题问的是：

- 最少跳几次到最后

核心贪心：

- 把每一次跳跃看成“一个覆盖区间”
- 在当前这一步能覆盖的范围内，尽量看看下一步最远能扩到哪
- 当走到当前区间终点时，就必须跳一次

### 口诀

`走完当前覆盖区间，就跳一步`

### 图解

以 `nums = [2,3,1,1,4]` 为例：

```text
下标: 0 1 2 3 4
数值: 2 3 1 1 4

第 1 次跳:
从下标 0 出发
当前能覆盖 [0, 2]

在 [0, 2] 里看下一步最远能到哪:
下标 1 可以到 4
所以下一次覆盖终点更新为 4

当走到当前终点 2 时:
必须跳第 2 次

总共 2 次
```

### 背景知识

- `end`：当前这一步最远能覆盖到哪里
- `farthest`：在当前区间里观察后，下一步最远能扩到哪里
- 走到 `end` 时，说明这一跳的能力已经用完，必须再跳一次

### Python

```python
class Solution:
    def jump(self, nums):
        steps = 0
        end = 0
        farthest = 0

        # 最后一个位置不需要再向后跳，所以遍历到 len(nums) - 2 即可
        for i in range(len(nums) - 1):
            # 记录当前区间里，下一步最远能去哪里
            farthest = max(farthest, i + nums[i])

            # 走到了当前这一步的边界，必须跳一次
            if i == end:
                steps += 1
                end = farthest

        return steps
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### 更优版

这个版本就是标准最优解。

## 763. 划分字母区间

### 题目

原题：[763. 划分字母区间](https://leetcode.cn/problems/partition-labels/)

给你一个字符串 s 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 "ababcc" 能够被分为 ["abab", "cc"]，但类似 ["aba", "bcc"] 或 ["ab", "ab", "cc"] 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 s 。

返回一个表示每个字符串片段的长度的列表。

示例 1：

输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。

示例 2：

输入：s = "eccbbbbdec"
输出：[10]

提示：

- 1 <= s.length <= 500

- s 仅由小写英文字母组成

### 思路

想把字符串尽量分成多个片段，并保证：

- 同一个字母只能出现在一个片段里

做法：

1. 先记录每个字符最后一次出现的位置
2. 遍历字符串时，不断更新当前片段的最远右边界
3. 当遍历位置走到这个右边界时，就可以切一刀

### 口诀

`先记每个字母最后出现位置，走到最远边界就切`

### 图解

以 `s = "ababcbacadefegdehijhklij"` 为例：

```text
先看最后出现位置:
a 最后在 8
b 最后在 5
c 最后在 7

从左往右走:

走到 a:
当前片段最远右边界 = 8

继续走到 b、a、b、c...
虽然中间字符不同，但它们最后出现位置都没有超过 8

当走到下标 8:
说明 [0, 8] 这个片段已经封闭
可以切出来，长度是 9
```

### 背景知识

- 字典 `last[ch]` 用来记录字符 `ch` 最后出现的位置
- `res.append(length)` 把一个片段长度加入答案

### Python

```python
class Solution:
    def partitionLabels(self, s):
        # 记录每个字符最后出现的位置
        last = {}
        for i, ch in enumerate(s):
            last[ch] = i

        res = []
        start = 0
        end = 0

        for i, ch in enumerate(s):
            # 当前片段的最远右边界
            end = max(end, last[ch])

            # 走到边界，说明可以切分
            if i == end:
                res.append(end - start + 1)
                start = i + 1

        return res
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

说明：

- 严格说字典用了空间
- 但字母种类固定时，可以视为常数级

### 更优版

这个版本就是最容易记也最常用的版本。
