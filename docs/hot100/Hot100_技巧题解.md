## 136. 只出现一次的数字

### 题目

原题：[136. 只出现一次的数字](https://leetcode.cn/problems/single-number/)

给你一个 非空 整数数组 nums ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

示例 1 ：

输入：nums = [2,2,1]

输出：1

示例 2 ：

输入：nums = [4,1,2,1,2]

输出：4

示例 3 ：

输入：nums = [1]

输出：1

提示：

- 1 <= nums.length <= 3 * 104

- -3 * 104 <= nums[i] <= 3 * 104

- 除了某个元素只出现一次以外，其余每个元素均出现两次。

### 思路

这题先别急着上异或，先理解它为什么有用。

题目说：

- 只有一个数出现 `1` 次
- 其他数都出现 `2` 次

这意味着：如果有一种运算，能让“相同的两个数一碰就消失”，那最后剩下的就一定是答案。

这种运算就是 `异或 ^`。

异或最关键的 3 条性质：

- `a ^ a = 0`，相同的数会抵消
- `a ^ 0 = a`，和 0 异或还是自己
- 异或满足交换律和结合律，所以顺序不重要

所以把所有数从头到尾异或一遍，成对的数都会消掉，最后只剩那个单独出现一次的数。

### 口诀

`成对异或会抵消`

### 图解

以 `nums = [4,1,2,1,2]` 为例：

```text
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

### 背景知识

- `^` 是按位异或
- 小白刚开始不需要真的手算二进制，记住“相同抵消”就够了
- 这题的技巧重点不是位运算细节，而是“找到一种能抵消重复元素的运算”

### Python

```python
class Solution:
    def singleNumber(self, nums):
        # 一开始先放 0
        # 因为 num ^ 0 = num，不会影响答案
        ans = 0

        for num in nums:
            # 不断把当前数字并入答案
            # 成对出现的数字最后会互相抵消掉
            ans ^= num

        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 169. 多数元素


### 题目

原题：[169. 多数元素](https://leetcode.cn/problems/majority-element/)

给定一个大小为 n 的数组 nums ，返回其中的多数元素。多数元素是指在数组中出现次数 大于 ⌊ n/2 ⌋ 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

示例 1：

输入：nums = [3,2,3]
输出：3

示例 2：

输入：nums = [2,2,1,1,1,2,2]
输出：2

提示：

- n == nums.length

- 1 <= n <= 5 * 104

- -109 <= nums[i] <= 109

- 输入保证数组中一定有一个多数元素。

进阶：尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

### 简单版思路

最简单的办法：

- 统计每个数出现次数
- 返回次数最多的那个

### 简单版口诀

`先数次数`

### 简单版 Python

```python
class Solution:
    def majorityElement(self, nums):
        count = {}

        for num in nums:
            count[num] = count.get(num, 0) + 1

        limit = len(nums) // 2

        for num in count:
            if count[num] > limit:
                return num
```

### 简单版复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 更优版思路

更经典的是 Boyer-Moore 投票法。

先解释这个技巧在干什么：

题目保证“多数元素”出现次数 `> n // 2`。

这说明一件事：

`它的数量，比其他所有数加起来还多。`

所以如果我们不断做“相同加一票、不同减一票”的抵消，最后还能活到最后的，一定就是它。

这不是魔法，本质上是在做“成对抵消”。

### 更优版口诀

`相同加票，不同减票，票清零就换人`

### 图解

```text
candidate = 当前候选人
count = 当前票数

遇到相同的:
count + 1

遇到不同的:
count - 1

如果 count 变成 0:
说明前面互相抵消完了
换下一个数做候选人
```

### 更优版 Python

```python
class Solution:
    def majorityElement(self, nums):
        # candidate 表示当前候选人
        candidate = None

        # count 表示当前候选人的净票数
        count = 0

        for num in nums:
            # 如果票数清零，就换一个新的候选人
            if count == 0:
                candidate = num

            # 遇到和候选人相同的，就加票
            # 不同的，就减票
            if num == candidate:
                count += 1
            else:
                count -= 1

        return candidate
```

### 更优版复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 75. 颜色分类

### 题目

原题：[75. 颜色分类](https://leetcode.cn/problems/sort-colors/)

给定一个包含红色、白色和蓝色、共 n 个元素的数组 nums ，原地 对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。

我们使用整数 0、 1 和 2 分别表示红色、白色和蓝色。

必须在不使用库内置的 sort 函数的情况下解决这个问题。

示例 1：

输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]

示例 2：

输入：nums = [2,0,1]
输出：[0,1,2]

提示：

- n == nums.length

- 1 <= n <= 300

- nums[i] 为 0、1 或 2

进阶：

- 你能想出一个仅使用常数空间的一趟扫描算法吗？

### 思路

这题先不要背指针名字，先想“我要把数组分成哪几块”。

因为数组里只有：

- `0`
- `1`
- `2`

所以最自然的目标就是把它整理成 3 个区域：

- 左边全是 `0`
- 中间全是 `1`
- 右边全是 `2`

这就是经典的 `荷兰国旗问题`。

这个技巧的本质是：

`一边扫描数组，一边把元素扔到它该去的区域。`

### 口诀

`0 放左边，2 放右边，1 留中间`

### 图解

```text
[0 区域][1 区域][未处理][2 区域]

low      cur           high

如果 nums[cur] == 0:
和 low 交换，low++, cur++

如果 nums[cur] == 1:
cur++

如果 nums[cur] == 2:
和 high 交换，high--
注意 cur 先别动，因为换过来的数还没看
```

### 背景知识

- 交换写法：
  `nums[a], nums[b] = nums[b], nums[a]`
- `low` 左边已经整理好，全部是 0
- `high` 右边已经整理好，全部是 2
- `cur` 负责扫描“还没处理的区域”

### Python

```python
class Solution:
    def sortColors(self, nums):
        # low 左边都应该是 0
        low = 0

        # cur 负责扫描当前还没处理的位置
        cur = 0

        # high 右边都应该是 2
        high = len(nums) - 1

        while cur <= high:
            if nums[cur] == 0:
                # 当前数是 0，就把它扔到左边 0 区域
                nums[low], nums[cur] = nums[cur], nums[low]
                low += 1
                cur += 1
            elif nums[cur] == 1:
                # 1 本来就该在中间，直接看下一个
                cur += 1
            else:
                # 当前数是 2，就把它扔到右边 2 区域
                # 注意：这里 cur 不能先加 1
                # 因为从 high 换过来的新数还没检查
                nums[cur], nums[high] = nums[high], nums[cur]
                high -= 1
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 31. 下一个排列

### 题目

原题：[31. 下一个排列](https://leetcode.cn/problems/next-permutation/)

整数数组的一个 排列 就是将其所有成员以序列或线性顺序排列。

- 例如，arr = [1,2,3] ，以下这些都可以视作 arr 的排列：[1,2,3]、[1,3,2]、[3,1,2]、[2,3,1] 。

整数数组的 下一个排列 是指其整数的下一个字典序更大的排列。更正式地，如果数组的所有排列根据其字典顺序从小到大排列在一个容器中，那么数组的 下一个排列 就是在这个有序容器中排在它后面的那个排列。如果不存在下一个更大的排列，那么这个数组必须重排为字典序最小的排列（即，其元素按升序排列）。

- 例如，arr = [1,2,3] 的下一个排列是 [1,3,2] 。

- 类似地，arr = [2,3,1] 的下一个排列是 [3,1,2] 。

- 而 arr = [3,2,1] 的下一个排列是 [1,2,3] ，因为 [3,2,1] 不存在一个字典序更大的排列。

给你一个整数数组 nums ，找出 nums 的下一个排列。

必须 原地 修改，只允许使用额外常数空间。

示例 1：

输入：nums = [1,2,3]
输出：[1,3,2]

示例 2：

输入：nums = [3,2,1]
输出：[1,2,3]

示例 3：

输入：nums = [1,1,5]
输出：[1,5,1]

提示：

- 1 <= nums.length <= 100

- 0 <= nums[i] <= 100

### 思路

这题如果直接背步骤，很容易背忘。

先把目标说清楚：

`不是随便找一个更大的排列，而是找“刚好比当前排列大一点点”的那个。`

所以我们要尽量：

- 先保证前面不动太多
- 只在靠右的位置做最小幅度变大

具体技巧分 4 步：

1. 从右往左找“拐点” `i`
   也就是第一个满足 `nums[i] < nums[i+1]` 的位置
2. 这个拐点右边是一段降序区间
3. 从右往左找第一个比 `nums[i]` 大的数 `j`
   因为从右往左找，找到的就是“刚好大一点”的那个
4. 交换后，把右边这段降序区间反转成最小升序

这样得到的就是“下一个排列”。

### 口诀

`先找拐点，再找刚好更大的，交换后反转尾巴`

### 图解

以 `1 2 3 6 5 4` 为例：

```text
从右往左看：
6 > 5 > 4 是一段降序尾巴
说明这段已经是“这个前缀下能排出的最大尾巴”

所以要想只变大一点点，
就只能去动它左边的拐点 3

再从右往左找第一个比 3 大的数:
找到 4

交换:
1 2 4 6 5 3

把后面反转成最小:
1 2 4 3 5 6
```

### 背景知识

- “从右往左找第一个升序位置”：
  就是找 `nums[i] < nums[i + 1]`
- 右边那一段原本是降序，交换后反转就能变成最小升序
- 如果整个数组从右到左一直都是降序，比如 `3 2 1`
  说明它已经是最大排列了，直接反转成最小排列 `1 2 3`

### Python

```python
class Solution:
    def nextPermutation(self, nums):
        n = len(nums)
        i = n - 2

        # 1. 从右往左找第一个 nums[i] < nums[i+1] 的位置
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1

        if i >= 0:
            j = n - 1

            # 2. 从右往左找第一个比 nums[i] 大的数
            while nums[j] <= nums[i]:
                j -= 1

            # 交换拐点和“刚好比它大”的那个数
            nums[i], nums[j] = nums[j], nums[i]

        # 3. 反转后半部分
        # 因为后半部分原本是降序，反转后会变成最小升序
        left = i + 1
        right = n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 287. 寻找重复数


### 题目

原题：[287. 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number/)

给定一个包含 n + 1 个整数的数组 nums ，其数字都在 [1, n] 范围内（包括 1 和 n），可知至少存在一个重复的整数。

假设 nums 只有 一个重复的整数 ，返回 这个重复的数 。

你设计的解决方案必须 不修改 数组 nums 且只用常量级 O(1) 的额外空间。

示例 1：

输入：nums = [1,3,4,2,2]
输出：2

示例 2：

输入：nums = [3,1,3,4,2]
输出：3

示例 3 :

输入：nums = [3,3,3,3,3]
输出：3

提示：

- 1 <= n <= 105

- nums.length == n + 1

- 1 <= nums[i] <= n

- nums 中 只有一个整数 出现 两次或多次 ，其余整数均只出现 一次

进阶：

- 如何证明 nums 中至少存在一个重复的数字?

- 你可以设计一个线性级时间复杂度 O(n) 的解决方案吗？

### 简单版思路

最容易理解的方法：

- 用集合 `set`
- 遍历时看这个数是否已经出现过

### 简单版口诀

`见过就返回`

### 简单版 Python

```python
class Solution:
    def findDuplicate(self, nums):
        seen = set()

        for num in nums:
            if num in seen:
                return num
            seen.add(num)
```

### 简单版复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### 更优版思路

先说为什么这题能和“链表判环”扯上关系。

数组里的数都在 `1 ~ n` 之间，所以你可以把它想成：

`下标 x 会跳到下标 nums[x]。`

比如：

- 在下标 `0`，下一步跳到 `nums[0]`
- 在下标 `1`，下一步跳到 `nums[1]`

这样整个数组就像一条“用下标串起来的链”。

题目里有重复数，意味着：

`会有两个不同位置，指向同一个下标。`

一旦两条路汇到一起，后面就会绕成环。

而这个环的入口，恰好就是重复数。

所以这题的技巧是：

`把数组看成链表，再用 Floyd 快慢指针找环入口。`

### 更优版口诀

`把数组看成链表，重复数就是环入口`

### 图解

以 `nums = [1,3,4,2,2]` 为例：

```text
下标 -> 值
0 -> 1
1 -> 3
3 -> 2
2 -> 4
4 -> 2

于是形成:
0 -> 1 -> 3 -> 2 -> 4
               ^    |
               |____|

环入口是 2
所以重复数是 2
```

### 背景知识

- `slow = nums[slow]`：慢指针每次走一步
- `fast = nums[nums[fast]]`：快指针每次走两步
- Floyd 判环法常用于链表有环问题
- 第 1 阶段的目标是“先在环里相遇”
- 第 2 阶段的目标是“找到环入口”

### 更优版 Python

```python
class Solution:
    def findDuplicate(self, nums):
        # 先让快慢指针都从同一个起点出发
        slow = nums[0]
        fast = nums[0]

        # 第 1 阶段：先在环里相遇
        while True:
            # 慢指针走 1 步
            slow = nums[slow]

            # 快指针走 2 步
            fast = nums[nums[fast]]
            if slow == fast:
                break

        # 第 2 阶段：一个从起点走，一个从相遇点走
        # 再次相遇的位置就是环入口，也就是重复数
        slow = nums[0]
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]

        return slow
```

### 更优版复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

## 二、最后的背诵总结

- `136 只出现一次的数字`：异或抵消
- `169 多数元素`：投票法，相同加票，不同减票
- `75 颜色分类`：0 左 1 中 2 右
- `31 下一个排列`：找拐点，找更大，交换，反转尾巴
- `287 寻找重复数`：简单版用 set，更优版看成链表找环入口
