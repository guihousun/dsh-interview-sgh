## 1. 哈希：1. 两数之和

题目：给定数组 `nums` 和目标值 `target`，返回两个数下标，使它们的和等于 `target`。

口诀：边遍历边找另一半；字典存“数字 -> 下标”。

思路伪代码：

```text
创建字典 pos
遍历 nums，每次拿到下标 i 和数字 num
    need = target - num
    如果 need 在 pos 里：
        返回 [pos[need], i]
    否则：
        pos[num] = i
```

```python
def solve(nums, target):
    # pos: key 是数字，value 是这个数字的下标
    pos = {}

    for i, num in enumerate(nums):
        # 当前数字 num 需要的另一半
        need = target - num

        # 如果 need 之前出现过，直接返回答案
        if need in pos:
            return [pos[need], i]

        # 否则记录当前数字
        pos[num] = i

    return []


nums = [2, 7, 11, 15]
target = 9
print(solve(nums, target))
```

## 2. 双指针：283. 移动零

题目：把数组里的所有 `0` 移到末尾，同时保持非零元素相对顺序。

口诀：`slow` 指向下一个非零数该放的位置。

思路伪代码：

```text
slow = 0
遍历数组每个位置 fast
    如果 nums[fast] 不是 0：
        nums[slow] = nums[fast]
        slow 向后移动
从 slow 到数组末尾：
    全部改成 0
返回 nums
```

```python
def solve(nums):
    # slow 表示下一个非零元素应该放的位置
    slow = 0

    # 第一遍：把所有非零数按原顺序放到前面
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow] = nums[fast]
            slow += 1

    # 第二遍：slow 后面全部补 0
    for i in range(slow, len(nums)):
        nums[i] = 0

    return nums


nums = [0, 1, 0, 3, 12]
print(solve(nums))
```

## 3. 链表：206. 反转链表

题目：反转一个单链表。

口诀：三指针；先存后继，再反转指向。

思路伪代码：

```text
prev = None
cur = head
当 cur 不为空：
    nxt = cur.next        先保存后继
    cur.next = prev       反转当前指针
    prev = cur            prev 向后走
    cur = nxt             cur 向后走
返回 prev
```

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


def solve(head):
    # prev 是已经反转好的前半部分头节点
    prev = None

    # cur 是当前正在处理的节点
    cur = head

    while cur:
        # 先保存后面的节点，防止断链
        nxt = cur.next

        # 反转当前节点指向
        cur.next = prev

        # prev 和 cur 一起向后移动
        prev = cur
        cur = nxt

    # prev 最后就是新链表头
    return prev
```

## 4. 二叉树：104. 二叉树的最大深度

题目：求二叉树最大深度。

口诀：当前深度 = 左右子树更深的那个 + 1。

思路伪代码：

```text
如果 root 为空：
    返回 0
left_depth = 左子树最大深度
right_depth = 右子树最大深度
返回 max(left_depth, right_depth) + 1
```

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


def solve(root):
    # 空树深度是 0
    if not root:
        return 0

    # 分别求左右子树深度
    left_depth = solve(root.left)
    right_depth = solve(root.right)

    # 当前节点贡献 1 层
    return max(left_depth, right_depth) + 1
```

## 5. 二分查找：35. 搜索插入位置

题目：在有序数组中找 `target`，如果不存在，返回它应该插入的位置。

口诀：标准二分；找不到就返回 `left`。

思路伪代码：

```text
left = 0
right = len(nums) - 1
当 left <= right：
    mid = 中间位置
    如果 nums[mid] == target：
        返回 mid
    如果 nums[mid] < target：
        left = mid + 1
    否则：
        right = mid - 1
返回 left
```

```python
def solve(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = (left + right) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    # 循环结束时，left 就是插入位置
    return left


nums = [1, 3, 5, 6]
target = 5
print(solve(nums, target))
```

## 6. 栈：20. 有效的括号

题目：判断括号字符串是否合法。

口诀：左括号入栈，右括号看栈顶。

思路伪代码：

```text
建立右括号到左括号的映射 mp
创建栈 stack
遍历字符串 ch
    如果 ch 是右括号：
        如果栈空，或者栈顶不是对应左括号：
            返回 False
        否则弹出栈顶
    否则：
        左括号入栈
遍历结束后：
    如果栈为空返回 True，否则 False
```

```python
def solve(s):
    # key 是右括号，value 是对应左括号
    mp = {
        ')': '(',
        ']': '[',
        '}': '{'
    }

    stack = []

    for ch in s:
        if ch in mp:
            # 右括号必须匹配栈顶左括号
            if not stack or stack[-1] != mp[ch]:
                return False
            stack.pop()
        else:
            # 左括号入栈
            stack.append(ch)

    # 没有多余左括号才合法
    return not stack


s = "()[]{}"
print(solve(s))
```

## 7. 贪心：121. 买卖股票的最佳时机

题目：给定每天股价，只能买卖一次，求最大利润。

口诀：一路记录最低买入价；每天尝试卖出更新利润。

思路伪代码：

```text
min_price = 第一天价格
ans = 0
遍历每一天 price
    如果今天卖出，利润 = price - min_price
    用这个利润更新 ans
    用 price 更新 min_price
返回 ans
```

```python
def solve(prices):
    # min_price 记录目前见过的最低价格
    min_price = prices[0]

    # ans 记录最大利润
    ans = 0

    for price in prices:
        # 如果今天卖出，利润是 price - min_price
        ans = max(ans, price - min_price)

        # 更新最低买入价
        min_price = min(min_price, price)

    return ans


prices = [7, 1, 5, 3, 6, 4]
print(solve(prices))
```

## 8. 动态规划：70. 爬楼梯

题目：每次可以爬 1 或 2 阶，爬到第 `n` 阶有多少种方法。

口诀：到第 n 阶 = 从 n-1 上来 + 从 n-2 上来。

思路伪代码：

```text
如果 n <= 2：
    返回 n
a = 1      到第 1 阶的方法数
b = 2      到第 2 阶的方法数
从第 3 阶遍历到第 n 阶：
    c = a + b
    a = b
    b = c
返回 b
```

```python
def solve(n):
    # n 为 1 或 2 时，答案就是 n
    if n <= 2:
        return n

    # a 表示到第 1 阶的方法数，b 表示到第 2 阶的方法数
    a = 1
    b = 2

    for i in range(3, n + 1):
        # 当前阶数的方法数
        c = a + b

        # 向后滚动
        a = b
        b = c

    return b


n = 5
print(solve(n))
```

# 二、基础手撕算法：快速排序

快排不是 Hot100 官方题号，但属于面试常见基础手撕算法，放在 Easy 后面单独背。

## 快速排序

题目：给定数组 `nums`，将数组从小到大排序。

口诀：选基准，左右分区，递归排序。

思路伪代码：

```text
定义 quick_sort(left, right)：
    如果 left >= right：
        返回
    选 nums[left] 作为基准 pivot
    i = left
    j = right
    当 i < j：
        从右往左找小于 pivot 的数
        从左往右找大于 pivot 的数
        如果 i < j，交换 nums[i] 和 nums[j]
    把 pivot 放到最终位置 i
    递归排序左半部分
    递归排序右半部分

调用 quick_sort(0, len(nums)-1)
返回 nums
```

```python
def solve(nums):
    def quick_sort(left, right):
        # 区间里 0 个或 1 个元素，不需要排序
        if left >= right:
            return

        # 选最左边的数作为基准
        pivot = nums[left]

        # i、j 从左右两端向中间走
        i = left
        j = right

        while i < j:
            # 从右往左找第一个小于 pivot 的数
            while i < j and nums[j] >= pivot:
                j -= 1

            # 从左往右找第一个大于 pivot 的数
            while i < j and nums[i] <= pivot:
                i += 1

            # 找到一大一小，交换它们
            if i < j:
                nums[i], nums[j] = nums[j], nums[i]

        # i 和 j 相遇后，把 pivot 放到最终位置
        nums[left] = nums[i]
        nums[i] = pivot

        # 分别排序 pivot 左边和右边
        quick_sort(left, i - 1)
        quick_sort(i + 1, right)

    quick_sort(0, len(nums) - 1)
    return nums


nums = [5, 2, 3, 1, 4]
print(solve(nums))
```

## 10. 滑动窗口：3. 无重复字符的最长子串

题目：返回字符串中不含重复字符的最长子串长度。

口诀：窗口里不能有重复；重复就移动左边界。

思路伪代码：

```text
seen = 空集合
left = 0
ans = 0
遍历字符串，right 是右边界，ch 是当前字符
    当 ch 已经在 seen 中：
        从 seen 中移除 s[left]
        left 向右移动
    把 ch 加入 seen
    更新 ans = max(ans, right - left + 1)
返回 ans
```

```python
def solve(s):
    # seen 存当前窗口里的字符
    seen = set()
    left = 0
    ans = 0

    for right, ch in enumerate(s):
        # 如果 ch 已经在窗口里，就缩小左边界
        while ch in seen:
            seen.remove(s[left])
            left += 1

        # 把当前字符加入窗口
        seen.add(ch)

        # 更新最大窗口长度
        ans = max(ans, right - left + 1)

    return ans


s = "abcabcbb"
print(solve(s))
```

## 11. 普通数组：53. 最大子数组和

题目：找出连续子数组，使其和最大，返回最大和。

口诀：前面和如果拖后腿，就从当前数重新开始。

思路伪代码：

```text
cur = nums[0]      以当前位置结尾的最大和
ans = nums[0]      全局最大和
从第二个数开始遍历：
    cur = max(接上前面, 从当前数重新开始)
    ans = max(ans, cur)
返回 ans
```

```python
def solve(nums):
    # cur 表示以当前位置结尾的最大子数组和
    cur = nums[0]

    # ans 表示全局最大子数组和
    ans = nums[0]

    for i in range(1, len(nums)):
        # 要么接上前面的子数组，要么从当前数重新开始
        cur = max(cur + nums[i], nums[i])

        # 更新全局最大值
        ans = max(ans, cur)

    return ans


nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
print(solve(nums))
```

## 12. 矩阵：73. 矩阵置零

题目：如果矩阵中某个元素为 `0`，则把它所在行和列全部置为 `0`。

口诀：先记哪些行列有 0，再统一置 0。

思路伪代码：

```text
rows = 空集合
cols = 空集合
第一遍扫描矩阵：
    如果 matrix[i][j] == 0：
        记录第 i 行
        记录第 j 列
第二遍扫描矩阵：
    如果 i 在 rows 中，或者 j 在 cols 中：
        matrix[i][j] = 0
返回 matrix
```

```python
def solve(matrix):
    m = len(matrix)
    n = len(matrix[0])

    # 记录哪些行、哪些列需要置零
    rows = set()
    cols = set()

    # 第一遍：找到所有 0 的位置
    for i in range(m):
        for j in range(n):
            if matrix[i][j] == 0:
                rows.add(i)
                cols.add(j)

    # 第二遍：如果当前格子所在行或列出现过 0，就置零
    for i in range(m):
        for j in range(n):
            if i in rows or j in cols:
                matrix[i][j] = 0

    return matrix


matrix = [
    [1, 1, 1],
    [1, 0, 1],
    [1, 1, 1]
]
print(solve(matrix))
```

## 13. 图论：200. 岛屿数量

题目：`'1'` 是陆地，`'0'` 是水，求岛屿数量。相邻只看上下左右。

口诀：遇到一个 1 就计数，然后 DFS 淹掉整座岛。

思路伪代码：

```text
定义 dfs(i, j)：
    如果越界，或当前位置不是 '1'：
        返回
    把当前位置改成 '0'
    dfs 上下左右四个方向

ans = 0
遍历每个格子：
    如果当前格子是 '1'：
        ans += 1
        dfs(i, j)
返回 ans
```

```python
def solve(grid):
    m = len(grid)
    n = len(grid[0])

    def dfs(i, j):
        # 越界或不是陆地，直接返回
        if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] != '1':
            return

        # 标记访问过
        grid[i][j] = '0'

        # 四个方向继续搜索
        dfs(i + 1, j)
        dfs(i - 1, j)
        dfs(i, j + 1)
        dfs(i, j - 1)

    ans = 0

    for i in range(m):
        for j in range(n):
            if grid[i][j] == '1':
                ans += 1
                dfs(i, j)

    return ans


grid = [
    ['1', '1', '0'],
    ['0', '1', '0'],
    ['1', '0', '1']
]
print(solve(grid))
```

## 14. 回溯：78. 子集

题目：给定数组 `nums`，返回所有子集。

口诀：每到一个节点先收集答案，再往后选。

思路伪代码：

```text
res = []
path = []
定义 backtrack(start)：
    把当前 path 复制加入 res
    从 start 遍历到数组末尾：
        选择 nums[i]，加入 path
        backtrack(i + 1)
        撤销选择，弹出 path 最后一个数
调用 backtrack(0)
返回 res
```

```python
def solve(nums):
    res = []
    path = []

    def backtrack(start):
        # 当前 path 本身就是一个子集
        res.append(path[:])

        # 从 start 开始继续选择后面的数字
        for i in range(start, len(nums)):
            # 选择 nums[i]
            path.append(nums[i])

            # 下次只能从 i + 1 后面选，避免重复
            backtrack(i + 1)

            # 撤销选择
            path.pop()

    backtrack(0)
    return res


nums = [1, 2, 3]
print(solve(nums))
```

## 15. 多维动态规划：62. 不同路径

题目：机器人从左上角走到右下角，只能向右或向下，求路径数量。

口诀：当前格子路径数 = 上面 + 左边。

思路伪代码：

```text
创建 m 行 n 列 dp
第一行全部填 1
第一列全部填 1
从第 1 行第 1 列开始遍历：
    dp[i][j] = dp[i-1][j] + dp[i][j-1]
返回右下角 dp[m-1][n-1]
```

```python
def solve(m, n):
    # 创建 m 行 n 列的 dp
    dp = []
    for i in range(m):
        dp.append([0] * n)

    # 第一列只能一直向下走，路径数都是 1
    for i in range(m):
        dp[i][0] = 1

    # 第一行只能一直向右走，路径数都是 1
    for j in range(n):
        dp[0][j] = 1

    # 中间格子可以从上面或左边来
    for i in range(1, m):
        for j in range(1, n):
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

    return dp[m - 1][n - 1]


m = 3
n = 7
print(solve(m, n))
```
