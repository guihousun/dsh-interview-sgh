# Hot100 哈希题解

只整理 LeetCode Hot 100 里属于 `哈希` 的题。

核心：`用空间换时间，快速判断某个值是否见过、出现过几次、是否存在配对关系。`

## 一、哈希前置知识：这类题在干什么

哈希题最常见的任务，不是“把数据排好序”，而是：

- 很快判断一个东西在不在
- 很快统计它出现了几次
- 很快找到“它需要的搭档”

你可以把哈希表想成一个“查字典”的柜子：

- `key` 是你拿来查的东西，比如数字、字符、前缀和
- `value` 是你想记住的信息，比如下标、次数、是否出现过

什么时候该想到哈希：

- 题目里出现“是否存在”“有没有重复”“找配对”“统计次数”
- 你一看暴力做法像两层循环，想把“查找某个值”加速到 `O(1)`

要特别注意：

- 先想清楚字典里要存什么，不是所有题都只存“这个数出现过”
- 有的题要先查再放，顺序反了就会把自己和自己配对
- 哈希通常更省时间，但会多占一些空间

速记一句话：

`哈希的本质，就是把“以后还要查的信息”提前存起来。`

## 1. 两数之和


### 题目

原题：[1. 两数之和](https://leetcode.cn/problems/two-sum/)

给定一个整数数组 nums 和一个整数目标值 target，请你在该数组中找出 和为目标值 target 的那 两个 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

示例 1：

输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。

示例 2：

输入：nums = [3,2,4], target = 6
输出：[1,2]

示例 3：

输入：nums = [3,3], target = 6
输出：[0,1]

提示：

- 2 <= nums.length <= 104

- -109 <= nums[i] <= 109

- -109 <= target <= 109

- 只会存在一个有效答案

进阶：你可以想出一个时间复杂度小于 O(n2) 的算法吗？

### 思路

边遍历边把已经见过的数存进哈希表。当前数是 `num`，想找的配对数就是 `target - num`。如果它已经在哈希表里，答案立刻得到。

### 口诀

`边走边查配对数`

### 图解

```text
nums[i] = num
需要的数 = target - num
如果需要的数之前出现过 -> 直接返回
```

### Python

```python
class Solution:
    def twoSum(self, nums, target):
        pos = {}
        for i, num in enumerate(nums):
            need = target - num
            if need in pos:
                return [pos[need], i]
            pos[num] = i
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 49. 字母异位词分组


### 题目

原题：[49. 字母异位词分组](https://leetcode.cn/problems/group-anagrams/)

给你一个字符串数组，请你将 字母异位词 组合在一起。可以按任意顺序返回结果列表。

示例 1:

输入: strs = ["eat", "tea", "tan", "ate", "nat", "bat"]

输出: [["bat"],["nat","tan"],["ate","eat","tea"]]

解释：

- 在 strs 中没有字符串可以通过重新排列来形成 "bat"。

- 字符串 "nat" 和 "tan" 是字母异位词，因为它们可以重新排列以形成彼此。

- 字符串 "ate" ，"eat" 和 "tea" 是字母异位词，因为它们可以重新排列以形成彼此。

示例 2:

输入: strs = [""]

输出: [[""]]

示例 3:

输入: strs = ["a"]

输出: [["a"]]

提示：

- 1 <= strs.length <= 104

- 0 <= strs[i].length <= 100

- strs[i] 仅包含小写字母

### 思路

异位词排序后长得一样。把每个字符串排序后的结果当成键，原字符串放进对应分组里。

### 口诀

`排序后一样，就是一组`

### 图解

```text
eat -> aet
tea -> aet
ate -> aet
所以三者分到同一组
```

### Python

```python
from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs):
        groups = defaultdict(list)
        for s in strs:
            key = "".join(sorted(s))
            groups[key].append(s)
        return list(groups.values())
```

### 复杂度

- 时间复杂度：`O(n * k log k)`，`k` 是单词平均长度
- 空间复杂度：`O(nk)`

## 128. 最长连续序列


### 题目

原题：[128. 最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/)

给定一个未排序的整数数组 nums ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1：

输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。

示例 2：

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9

示例 3：

输入：nums = [1,0,1,2]
输出：3

提示：

- 0 <= nums.length <= 105

- -109 <= nums[i] <= 109

### 思路

把所有数放进集合。只从“连续序列起点”开始往后数，起点的特征是 `num - 1` 不在集合里。

### 口诀

`只从起点出发数长度`

### 图解

```text
100 不是起点，因为 99 不在就算起点
1 是起点 -> 1,2,3,4 长度 4
```

### Python

```python
class Solution:
    def longestConsecutive(self, nums):
        s = set(nums)
        ans = 0
        for num in s:
            if num - 1 not in s:
                cur = num
                length = 1
                while cur + 1 in s:
                    cur += 1
                    length += 1
                ans = max(ans, length)
        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`
