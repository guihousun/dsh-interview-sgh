一个运行在 DeepSeek Harness Web 中的 AI 面试练习助手。

它可以陪你完成从提问、作答、点评、讲解到继续练习的完整过程，也会保存你的练习记录，方便你随时回来复习和提升。

[立即安装](#安装) · [开始练习](#开始第一次练习) · [查看功能](#核心功能)

## 适合谁

- 准备技术开发岗位面试；
- 想复习八股，但不满足于只看题库答案；
- 想进行真实模拟面试，或根据简历提前押题；
- 想练习系统设计、故障排查等真实场景；
- 想刷力扣 Hot 100，并保留完成记录；
- 基础还不够扎实，希望有人先补前置知识、再按提示一步步带自己做题；
- 想持续保存回答，观察自己的进步。

## 核心功能

### 五种练习模式

| 模式 | 用来做什么 |
| --- | --- |
| 背八股 | 选择一个知识主题，练习常见技术面试问题，理解知识点并整理成可以直接表达的答案。 |
| 模拟面试 | 根据简历、目标岗位和面试偏好，进行接近真实面试的完整问答；面试官会持续追问，不提供答案和点评。 |
| 简历押题 | 根据简历、目标岗位、JD 和押题范围，练习最可能被问到的问题，并获得评分、点评和详细讲解。 |
| 场景题 | 练习系统设计、故障排查、性能问题和工程决策等开放式问题。 |
| 刷力扣 | 自由选择热题 100 里的任意题目，或者点名热题 100 之外的力扣题；题目材料、提示阶梯和讲解直接显示在对话里，并记录完成进度。 |

模拟面试中的手撕代码题也来自 Hot 100，但仍属于当前模拟面试的一部分。

### 刷力扣：自由选题、材料卡与引导模式

- **自由选题**：在「题库」里按题号、题名、题型或难度搜索，点「做这题」直接开始；热题 100 之外的题可以填题号与题名，插件会按你给的信息建题，不会替你编造题目。
- **材料卡直接进对话**：已有官方题面直接读取本地数据，题意、示例和约束无需重复让 AI 生成。AI 生成的前置知识、分级提示、常见误区和相似题会保存，并以 GenUI 卡片（`dsh-ui` 围栏）显示在对话正文里。
- **引导模式**：创建练习时显式选择「引导模式」或「标准模式」。引导模式先补前置知识、按提示阶梯带你推导，不主动给答案；标准模式按你的节奏，需要时再点提示或看答案。
- **提示阶梯**：题目卡的「提示」按钮逐级解锁提示，进度保存在题目上，问到哪一级、还剩几级都看得见。
- **自动记录完成题目**：作答收到 AI 点评，或结束/切换已有作答的练习后，题库自动打勾并更新完成进度。只阅读题目、看答案或无作答跳题不会标记；勾选表示练习过，仍可手动勾选或取消。历史记录只补齐缺失标记，保留手动调整。
- **做一遍，以后复用**：同题同语言的引导和通用 AI 讲解保存到题库，重做、刷新和重启都能直接读取，展开/收起不请求 AI。引导模式与标准模式分别缓存，讲解可跨模式复用；每次新练习的提示从零解锁。只有缺失、题面/参考解法变化或手动点「重新生成」时重新请求 AI；重复点击共用同一个请求，失败时旧内容仍可查看。
- **个性化点评单独保存**：代码分析仍检查本次提交，但优先使用已保存参考答案，不重复写整题讲解。针对个人作答的修正版不进入通用题库；旧记录只有确认不依赖个人作答的内容才自动回收为缓存。
- 需要「生成式 UI」渲染：材料卡由 [`@changfenhuang/dsh-genui`](https://github.com/omdsh-dev/dsh-genui) 渲染，未安装该插件时材料仍可在题目卡内查看。

### 题解库：把你自己整理的题解接进来

如果你有一份自己的 Hot 100 题解（按专题分册的 Markdown，或者从 LeetCode 导出的题目 CSV），可以用导入脚本把它变成插件的**本地题解库**：

```sh
node scripts/import-leetcode-reference.mjs --notes "D:\path\to\Hot100_题解"            # 官方题面实时抓取 + 笔记入库
node scripts/import-leetcode-reference.mjs --notes "D:\path\to\Hot100_题解" --official csv   # 只用本地 CSV 快照，不联网
node scripts/import-leetcode-reference.mjs --notes "D:\path\to\Hot100_题解" --verify         # 只核对快照与官方的漂移，不写库
```

- **官方题面是事实基线**：题意、示例、数据范围默认从 `leetcode.cn` 实时抓取（逐题失败回退本地 CSV），保存材料时也会自动以官方为准——模型把示例数字写错也会被纠正。
- **你的题解是参考素材**：思路、口诀、图解、代码、复杂度、易错点、专题前置知识都会入库（`interview_notes` 工具按题/按专题读取），但它们只是参考：讲解与材料由模型重新组织，可以改写、补充或重写，不会照抄。
- **来源可追溯**：材料卡与对话里的材料围栏都会写明「示例与数据范围取自官方题面；参考了你的《…》，已按需重写」。
- **不进发行包**：脚本运行时从你本地的目录读，官方题面缓存在该目录下，npm 包里只有解析器，不含任何 LeetCode 内容。

### 跟随宿主主题（含暗色模式）

插件界面只有一套样式，颜色全部走语义变量：亮色定义在 `body`，暗色定义在 `body[data-ds-dark-theme]`。在 DSH 设置里切到暗色主题后，题目卡、题库、练习工作台、时间轴、弹层、表单和徽标会一起换成暗色配色，不需要手动切换；暗色取值优先引用宿主的 `--dsw-*` 主题令牌，因此主题或皮肤调整令牌时插件会同步跟随。暗色下的正文、次要文字、标签与徽标对比度均达到 WCAG AA（≥ 4.5:1）。

### 完整的练习链路

在背八股、简历押题、场景题和刷力扣中，每道题都可以选择直接作答，或者先查看答案。作答后，AI 会围绕你的回答完成：

```text
提问 → 作答 → 评分与点评 → 知识讲解 → 可直接表达的答案
```

完成后可以重新作答、进入下一题或结束练习。重新作答不会覆盖以前的记录，方便对比每次回答的变化。

### 练习记录自动保存

题目和回答会自动保存；支持辅导的模式还会保存评分、点评、讲解和练习总结。你可以：

- 随时继续未完成的练习；
- 在新会话中切换到已有练习；
- 查看完整的练习历史；
- 对比同一道题的多次回答；
- 查看长期练习表现和薄弱主题。

### 可视化练习工作台

练习工作台提供统一的练习管理入口，可以查看：

- 进行中的练习；
- 已结束的练习档案；
- 力扣 Hot 100 题目和完成状态；
- 每道题的回答，以及支持辅导模式中的点评、讲解和参考答案。

同时支持搜索、筛选、切换、编辑、删除和导出练习。

### 本地保存，方便复习

练习数据默认保存在本机，不需要额外部署数据库或服务。真实简历和回答不会自动上传到其他系统。

## 安装

需要 DeepSeek Harness Web 和 Node.js 22.5 或更高版本。

```powershell
dsh plugin --profile web add dsh-interview
```

安装完成后重启 `dsh web`。

更新插件：

```powershell
dsh plugin --profile web update dsh-interview
```

## 开始第一次练习

1. 打开左侧栏设置上方的“面试训练”；
2. 点击“新建练习”；
3. 选择练习模式并填写对应内容；
4. 点击“开始练习”；
5. 在对话中回答题目；支持看答案的模式也可以直接点击“看答案”。

也可以直接在聊天中输入：

```text
新建练习
```

AI 会引导你完成练习配置。

## 五种模式怎么用

### 背八股

填写要复习的主题，例如：

- Java 并发；
- JVM；
- MySQL；
- Redis；
- Spring；
- 计算机网络。

适合集中复习一个知识领域，也适合在面试前快速检查自己能否把知识讲清楚。

### 模拟面试

填写简历、目标岗位、面试官风格、面试难度，并选择是否提供 JD 和是否进行手撕代码。开始后按真实面试节奏回答问题，面试官会根据你的回答继续追问，不提供“看答案”、评分或讲解。

适合完整检查自己对项目经历、技术能力和岗位要求的掌握情况。

### 简历押题

填写简历、目标岗位、是否提供 JD、押题范围和面试难度。插件会围绕你的经历和岗位要求生成高概率问题，作答后提供评分、点评、详细讲解和可以直接复述的答案。

适合在正式面试前集中补齐简历项目、技术选型和岗位匹配方面的薄弱点。

### 场景题

填写一个想练习的主题，例如：

- 线上接口突然变慢；
- 设计秒杀系统；
- 消息积压如何排查；
- 数据库性能下降如何处理。

适合练习问题拆解、方案设计、风险判断和工程落地。

### 刷力扣

选择 C++、Java、Python、C 或 Go，插件会从[力扣 Hot 100](https://leetcode.cn/studyplan/top-100-liked/)中抽取题目。

你可以查看题目原文、标记完成状态、查看算法讲解，并获得所选语言的完整代码。

## 练习过程

### 专题、难度与下一道

题库和力扣题目显示 easy、medium、hard 难度标签。新建或编辑刷力扣配置时可选择专题，并多选训练难度；选择“全部难度”恢复完整题单。

题库可按专题和难度筛选，并通过“按专题顺序训练”或“随机训练”直接开始。进行中的题目详情提供“按专题顺序下一道”和“随机下一道”，所选范围随练习保存并延续到后续题目。顺序模式沿用题库中该专题的顺序，到末尾后从第一道继续；随机模式优先选择范围内尚未完成的其他题目。没有匹配题目时会提示调整范围，不会改抽其他专题或难度。

工作台中的下一道会直接显示完整题面和代码区；每道题保留独立的练习记录，先前代码草稿仍按题目保存。

### 上传简历与参考资料

新建练习和“编辑配置”支持上传 PDF、Word（DOCX）、TXT 与 Markdown。模拟面试、简历押题的“上传简历”会将文件文字填入简历框，可检查并修改；所有模式都可通过“上传参考资料”添加岗位说明、项目介绍或面试笔记。资料可展开查看、编辑和移除。

单份文件最多 10 MB、PDF 最多 100 页、文字最多 60000 字符；最多 8 份参考资料，合计最多 180000 字符。解析在本地 DSH 服务中完成，练习保存提取的正文与文件信息，重新打开、切换会话和导出 Markdown 时仍可使用。原文件不会另存副本。AI 从已保存的配置读取资料，区分简历经历与参考案例，并把资料中的指令作为内容处理。

扫描版 PDF 没有可复制文字时会提示先做 OCR 或直接粘贴文字；加密 PDF 需先解密。上传失败会保留已有简历和参考资料。

### 作答

直接在对话中回答当前题目，AI 会保存你的回答并进行评分。

力扣题目卡片内可直接写代码；普通面试题点击“写代码”展开编辑区。也可以在“面试训练 → 进行中”选择题目，直接点击题目详情的“写代码”，无需先生成聊天卡片。编辑器提供行号、Tab/Shift+Tab 缩进、回车自动缩进和浏览器草稿保存，可附加思路说明。点击“AI 分析代码”（或 Ctrl/⌘+Enter）后，代码原样存入作答记录，AI 静态检查正确性、错误、边界条件和复杂度，不实际运行代码。力扣使用练习所选语言，普通题目可以选择语言。

点击右侧题目时间轴的 Q01 等题号，会在同一面板展示完整题目、引导、代码作答、历次记录和可折叠答案，不需要切换 tab。当前题直接显示编辑区；浏览历史题时，点击“写代码作答”切回那道题后开始。文字回答仍可直接发送到对话。

### 看答案

正确答案默认遮蔽，“展开正确答案”入口始终显示，也可以随时“收起正确答案”。展开时优先显示已保存的 AI 讲解，没有讲解时读取本地题解库中对应语言的参考答案；两者都没有时，可以手动点击“生成参考答案”。代码反馈和评分单独显示。模拟面试保持原有规则，不主动开放参考答案。

参考代码带适合新手的中文注释，解释关键变量、判断依据、状态更新和易错边界。热题 100 的本地 Python 题解已逐份审核，包含不同解法与独立示例；已知的原笔记版本再次导入时也会应用审核后的版本，用户后来修改过的实现不会被旧版本覆盖。AI 后续生成的答案和修正版也要求代码内注释，力扣答案保存时会检查基本注释。完整逐题记录见 [题解审核报告](docs/leetcode-answer-review.md)。

### 完整题目与引导

力扣题目在编辑器上方显示完整题意、输入输出示例、约束和进阶要求，优先使用本地保存的官方题面。没有保存题面时会标明缺失并提供官方题目链接。题目内容可以折叠，方便集中写代码。

引导模式打开当前题目时，会让当前会话的 AI 读取完整题面、示例、约束和参考笔记，生成针对本题的前置知识与四级引导。每级解释具体观察和原因，手推一个小例子，再提出自检问题；逐步推导到状态不变量、更新步骤和边界验证。标准模式可手动生成三级提示。

点击“解锁下一步引导”逐级查看，进度随题目保存；未来提示与正确答案不会自动展开。已有 AI 材料继续使用；旧版通用模板不再冒充 AI 引导。可点击“重新生成 AI 引导”重写材料，提示从第一级重新解锁，已有作答、答案和代码草稿保留。页面显示生成进度，投递失败或三分钟未完成时给出重试提示；生成调用当前会话所配置的模型。查看其他练习或已完成档案不会自动请求 AI。展开答案或解锁提示不会消耗代码作答卡片。

### 点评讲解

作答后会看到点评和详细讲解，包括回答中的优点、遗漏、错误、改进方向以及可以直接复述的答案。

### 重新作答

重新作答会保留此前的回答和点评，并新增一条作答记录，方便你比较前后变化。

### 下一题

完成当前题后，可以继续进入下一题。

### 结束练习

结束普通练习后，可以查看本次练习总结；力扣练习会保存本次刷题记录和完成情况。

## 练习工作台

练习工作台位于左侧栏设置上方的“面试训练”。

### 进行中

查看所有尚未结束的练习，可以继续练习、切换当前练习、查看详情或删除练习。

### 练习档案

查看已经结束的练习，包括题目、回答、评分、点评、讲解和总结，也可以重新打开继续练习。

### 热题 100

查看 Hot 100 的题目列表、题型、难度、原题地址和完成状态。

### 练习时间轴

进入某条练习后，可以通过时间轴查看题目、作答记录、点评和答案。

## 常见问题

### 练习记录会保存吗？

会。题目、每次回答、评分、点评、讲解和总结都会保存。

### 可以在新会话继续练习吗？

可以。在练习工作台切换到目标练习，然后在当前会话中继续即可。

### 重新作答会覆盖以前的回答吗？

不会。每次作答都会单独保存。

### 不想回答，可以直接看答案吗？

可以。点击“展开正确答案”查看已保存的讲解或本地参考题解；缺少答案时点击“生成参考答案”。

### 哪些操作需要 AI？

出题、点评、生成讲解和普通练习总结需要 AI。读取已保存的完整题面、本地引导和参考题解，以及搜索、筛选、切换、编辑、删除、导出和力扣完成状态管理可以直接在工作台完成。
