# Hot100 堆题解

核心：`堆不是“完全排好序”，而是“最值永远放在最前面，方便你反复拿”。`

## 堆预备课

### 1. 什么是堆

堆（heap）可以先理解成：

`一种特别适合快速拿最值的数据结构。`

它的重点不是把所有元素完整排好序，  
而是保证：

`最小值或者最大值，永远在最容易拿到的位置。`

### 2. 堆到底保证了什么

很多新手一开始会把堆和排序混在一起。

它们的差别是：

- 排序：想一次性把所有元素按顺序排好
- 堆：更关心“我能不能一直很快拿到当前最小值或最大值”

所以一定要先记住：

`堆只保证堆顶是最值，不保证剩下元素整体有序。`

### 3. Python 的 `heapq` 为什么默认是最小堆

所以只要题目出现这种味道，就该想到堆：

- 反复取第 `k` 大 / 第 `k` 小
- 数据不断进来，要随时维护中位数
- 只想保留“当前最重要的前 k 个”

Python 里的 `heapq` 默认是：

`最小堆`

也就是堆顶永远是当前最小值。

最常见操作是：

- `heapq.heapify(nums)`：把列表原地变成堆
- `heapq.heappush(heap, x)`：压入元素
- `heapq.heappop(heap)`：弹出堆顶最小值

### 4. 如果题目想要最大堆怎么办

Python 标准库没有直接提供最大堆，但常见技巧很简单：

`把数字取相反数后放进最小堆。`

比如本来想比较：

- `8`
- `5`
- `2`

那就改成压入：

- `-8`
- `-5`
- `-2`

这样最小堆会把 `-8` 放到前面，也就等价于原数字里的最大值 `8` 在堆顶。

### 5. 堆最适合什么时候用

如果题目不是要“完整排序”，只是要：

- 快速拿当前最小 / 最大
- 维护前 `k` 个
- 动态维护中位数或边界值

那通常就该优先考虑堆。

### 6. 堆和排序怎么选

你可以这样区分：

- `排序`：我要知道整体顺序
- `堆`：我只关心反复拿最值

如果题目只问：

- 第 `k` 大是谁
- 前 `k` 个是谁
- 当前中位数是多少

很多时候没必要把所有数据都排一遍。

### 7. 本专题先记住什么

小白先记这几句最实用：

- `堆最擅长快速拿最值`
- `堆不保证整体有序`
- `Python heapq 默认是最小堆`
- `想做最大堆，经常用负号技巧`
- `第 k 大、前 k 个、数据流，优先想堆`

## 215. 数组中的第K个最大元素


### 题目

原题：[215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

请注意，你需要找的是数组排序后的第 k 个最大的元素，而不是第 k 个不同的元素。

你必须设计并实现时间复杂度为 O(n) 的算法解决此问题。

示例 1:

输入: [3,2,1,5,6,4], k = 2
输出: 5

示例 2:

输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4

提示：

- 1 <= k <= nums.length <= 105

- -104 <= nums[i] <= 104

### 思路

题目要的是“第 k 大”，不是“全部排好序再拿一个”。

如果你把整个数组都排一遍，当然能做，但你其实做了很多没必要的工作。

更自然的思路是：

`我只关心最大的 k 个数，别的更小的数没必要一直留着。`

这时候最小堆很好用。

为什么不是最大堆？

因为我们想维护“当前最大的 k 个数”这个集合。

如果用最小堆来装这 k 个数，那么：

- 堆顶就是这 k 个数里最小的那个
- 也就正好是“当前第 k 大”

后面再来一个新数时：

- 如果它比堆顶还小，就不可能进入前 k 大，直接忽略
- 如果它比堆顶大，就把堆顶挤掉

### 口诀

`只保留最大的 k 个，堆顶就是第 k 大`

### 图解

```text
nums = [3, 2, 1, 5, 6, 4], k = 2

处理 3:
heap = [3]

处理 2:
heap = [2, 3]
这时堆里有目前最大的 2 个数：2 和 3
堆顶 2 就是“当前第 2 大”

处理 1:
heap = [1, 3, 2]
长度超过 2，弹出最小的 1
heap = [2, 3]

处理 5:
heap = [2, 3, 5]
弹出最小的 2
heap = [3, 5]

最后 heap = [5, 6]
堆顶 5 就是第 2 大
```

### 一步一步怎么做

1. 准备一个最小堆
2. 遍历数组里的每个数
3. 先把它放进堆
4. 如果堆的大小超过 `k`，就弹出最小值
5. 最后堆里刚好剩最大的 `k` 个数
6. 堆顶就是第 `k` 大

### 背景知识

- `heapq.heappush(heap, x)`：把元素放进最小堆
- `heapq.heappop(heap)`：弹出最小堆里的最小值
- Python 的堆不是“整体有序”，只保证 `heap[0]` 最小

### Python

```python
import heapq

class Solution:
    def findKthLargest(self, nums, k):
        # heap 用最小堆来维护“当前最大的 k 个数”
        heap = []

        for num in nums:
            # 先把当前数字放进堆里
            heapq.heappush(heap, num)

            # 如果超过 k 个，就把最小的那个踢掉
            # 因为它不可能属于“最大的 k 个数”了
            if len(heap) > k:
                heapq.heappop(heap)

        # 最后堆顶就是这 k 个数里最小的
        # 也就是整个数组的第 k 大
        return heap[0]
```

### 复杂度

- 时间复杂度：`O(n log k)`
- 空间复杂度：`O(k)`

## 347. 前 K 个高频元素


### 题目

原题：[347. 前 K 个高频元素](https://leetcode.cn/problems/top-k-frequent-elements/)

给你一个整数数组 nums 和一个整数 k ，请你返回其中出现频率前 k 高的元素。你可以按 任意顺序 返回答案。

示例 1：

输入：nums = [1,1,1,2,2,3], k = 2

输出：[1,2]

示例 2：

输入：nums = [1], k = 1

输出：[1]

示例 3：

输入：nums = [1,2,1,2,1,2,3,1,3,2], k = 2

输出：[1,2]

提示：

- 1 <= nums.length <= 105

- -104 <= nums[i] <= 104

- k 的取值范围是 [1, 数组中不相同的元素的个数]

- 题目数据保证答案唯一，换句话说，数组中前 k 个高频元素的集合是唯一的

进阶：你所设计算法的时间复杂度 必须 优于 O(n log n) ，其中 n 是数组大小。

### 思路

这题分两步看最清楚。

第一步不是堆，而是先搞清楚：

`每个数字出现了几次。`

比如：

`[1, 1, 1, 2, 2, 3]`

统计后就是：

- `1` 出现 `3` 次
- `2` 出现 `2` 次
- `3` 出现 `1` 次

第二步才是：

`怎么从这些 (数字, 频次) 里，快速保留频次最高的 k 个。`

这里和上一题非常像。

我们维护一个大小为 `k` 的最小堆，只不过堆里放的不是单个数字，而是：

`(频次, 数字)`

为什么把频次放前面？

因为 Python 比较元组时，会先比较第一个元素。
这样堆顶就是“当前前 k 名里频次最小的那个”。

### 口诀

`先数次数，再保留频次最高的 k 个`

### 图解

```text
nums = [1,1,1,2,2,3], k = 2

先统计：
1 -> 3 次
2 -> 2 次
3 -> 1 次

把 (频次, 数字) 放进最小堆：
(3, 1)
(2, 2)
(1, 3)

堆只保留 2 个元素
最后留下来的就是频次最高的两个数字
```

### 一步一步怎么做

1. 用 `Counter` 统计每个数字的出现次数
2. 准备一个最小堆
3. 遍历统计结果，把 `(频次, 数字)` 放进堆
4. 如果堆大小超过 `k`，就弹出最小频次
5. 最后堆里剩的就是前 `k` 个高频元素

### 背景知识

- `Counter(nums)`：可以快速统计每个元素出现次数
- `cnt.items()`：拿到 `(数字, 频次)` 这种键值对
- 元组 `(freq, num)` 放进最小堆时，会优先按 `freq` 比大小

### Python

```python
from collections import Counter
import heapq

class Solution:
    def topKFrequent(self, nums, k):
        # 第一步：统计每个数字出现了多少次
        cnt = Counter(nums)

        # 最小堆里存 (频次, 数字)
        heap = []

        for num, freq in cnt.items():
            heapq.heappush(heap, (freq, num))

            # 如果堆里超过 k 个
            # 就把频次最小的那个移除
            if len(heap) > k:
                heapq.heappop(heap)

        # 最后取出堆里的数字部分
        return [num for freq, num in heap]
```

### 复杂度

- 时间复杂度：`O(n log k)`
- 空间复杂度：`O(n)`

## 295. 数据流的中位数


### 题目

原题：[295. 数据流的中位数](https://leetcode.cn/problems/find-median-from-data-stream/)

中位数是有序整数列表中的中间值。如果列表的大小是偶数，则没有中间值，中位数是两个中间值的平均值。

- 例如 arr = [2,3,4] 的中位数是 3 。

- 例如 arr = [2,3] 的中位数是 (2 + 3) / 2 = 2.5 。

实现 MedianFinder 类:

- MedianFinder() 初始化 MedianFinder 对象。

- void addNum(int num) 将数据流中的整数 num 添加到数据结构中。

- double findMedian() 返回到目前为止所有元素的中位数。与实际答案相差 10-5 以内的答案将被接受。

示例 1：

输入
["MedianFinder", "addNum", "addNum", "findMedian", "addNum", "findMedian"]
[[], [1], [2], [], [3], []]
输出
[null, null, null, 1.5, null, 2.0]

解释
MedianFinder medianFinder = new MedianFinder();
medianFinder.addNum(1);    // arr = [1]
medianFinder.addNum(2);    // arr = [1, 2]
medianFinder.findMedian(); // 返回 1.5 ((1 + 2) / 2)
medianFinder.addNum(3);    // arr[1, 2, 3]
medianFinder.findMedian(); // return 2.0

提示:

- -105 <= num <= 105

- 在调用 findMedian 之前，数据结构中至少有一个元素

- 最多 5 * 104 次调用 addNum 和 findMedian

### 思路

这题难点在于：

`数字不是一次性给完，而是一个一个进来。`

如果每加一个数，你都把所有数重新排序，那就太慢了。

所以我们要维护一种结构，让它始终接近“中位数左右两边已经分好组”的状态。

最适合的做法是两堆：

- 左边一堆：放较小的一半数字
- 右边一堆：放较大的一半数字

并且满足：

1. 左边所有数都不大于右边所有数
2. 左边元素个数和右边元素个数最多只差 1

这样中位数就很好拿：

- 如果总数是奇数，中位数就是元素更多那一边的堆顶
- 如果总数是偶数，中位数就是两边堆顶的平均值

### 为什么是一大一小两种堆

左边我们需要快速拿到“较小一半里的最大值”，所以左边应该是最大堆。

右边我们需要快速拿到“较大一半里的最小值”，所以右边应该是最小堆。

但 Python 只有最小堆，没有直接的最大堆。

常见做法是：

`在左边堆里存相反数`

比如真实数字 `5`，存成 `-5`。
这样最小堆弹出的最小负数，反过来就是最大的真实值。

### 口诀

`左边管较小一半，右边管较大一半；左边取最大，右边取最小`

### 图解

```text
依次加入：1, 2, 3, 4

加入 1：
左边 = [1]
右边 = []
中位数 = 1

加入 2：
左边 = [1]
右边 = [2]
中位数 = (1 + 2) / 2

加入 3：
左边 = [1, 2]
右边 = [3]
中位数 = 2

加入 4：
左边 = [1, 2]
右边 = [3, 4]
中位数 = (2 + 3) / 2
```

### 一步一步怎么做

每来一个新数 `num`：

1. 先把它放进左边最大堆
2. 再把左边最大值挪到右边最小堆
3. 如果右边数量比左边还多，就再从右边挪一个最小值回左边

这样做的好处是：

- 自动保证左边的值整体不大于右边
- 自动把两边数量调平

### 背景知识

- `heapq` 默认是最小堆
- 左边堆 `small` 存相反数，所以取堆顶时要再取负号
- `small[0]` 不是最小值，而是“最小负数”，对应真实世界里的最大值

### Python

```python
import heapq

class MedianFinder:
    def __init__(self):
        # small 存“较小的一半”，但用相反数模拟最大堆
        self.small = []

        # large 存“较大的一半”，是真正的最小堆
        self.large = []

    def addNum(self, num):
        # 第一步：先放进左边堆
        # 因为左边是“最大堆模拟”，所以要放相反数
        heapq.heappush(self.small, -num)

        # 第二步：把左边当前最大的那个数，移动到右边
        # self.small 弹出来的是最小负数，对应真实最大值
        largest_in_small = -heapq.heappop(self.small)
        heapq.heappush(self.large, largest_in_small)

        # 第三步：如果右边元素太多了
        # 就把右边最小的那个搬回左边
        if len(self.large) > len(self.small):
            smallest_in_large = heapq.heappop(self.large)
            heapq.heappush(self.small, -smallest_in_large)

    def findMedian(self):
        # 如果左边多一个，说明总数是奇数
        # 中位数就是左边最大的那个
        if len(self.small) > len(self.large):
            return -self.small[0]

        # 否则总数是偶数
        # 中位数是左边最大值和右边最小值的平均数
        left_max = -self.small[0]
        right_min = self.large[0]
        return (left_max + right_min) / 2
```

### 复杂度

- `addNum` 时间复杂度：`O(log n)`
- `findMedian` 时间复杂度：`O(1)`
