# Hot100 二叉树题解

核心：`先想清楚这棵树长什么样，再想递归函数要交回什么结果。`

---

## 先修课：二叉树基础入门

如果你刚开始做二叉树题，最容易卡住的不是代码，而是`递归到底在干什么`。这一节先把树的基本概念和常见遍历方式讲清楚，再进题会顺很多。

### 1. 什么是二叉树？

二叉树的每个节点最多只有两个孩子：

- 左孩子 `left`
- 右孩子 `right`

最常见的节点定义长这样：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

一棵很小的树可以长成这样：

```text
    1
   / \
  2   3
```

这里：

- `1` 是根节点 `root`
- `2` 是 `1` 的左子树
- `3` 是 `1` 的右子树

一句话记忆：

`树题先分清当前节点、左子树、右子树。`

### 2. 前序、中序、后序到底是什么？

它们本质上都是在问：`遍历到一个节点时，你准备什么时候处理它？`

设当前节点是 `root`：

- 前序：`根 -> 左 -> 右`
- 中序：`左 -> 根 -> 右`
- 后序：`左 -> 右 -> 根`

看这棵树：

```text
    1
   / \
  2   3
```

对应结果是：

- 前序：`[1, 2, 3]`
- 中序：`[2, 1, 3]`
- 后序：`[2, 3, 1]`

你可以这样记：

- 前序：一到节点先处理
- 中序：左边处理完再处理自己
- 后序：左右都处理完最后处理自己

### 3. 递归函数的返回值是什么意思？

这是二叉树题最重要的一点。

很多题都不是“机械地往下递归”，而是：`让左右子树先算出答案，再把答案交给当前节点。`

比如：

- 求最大深度时，递归函数可以返回“这棵子树的最大深度”
- 求直径时，递归函数可以返回“从当前节点往下走的最长单边长度”
- 验证 BST 时，递归里会利用“左边范围”和“右边范围”来判断是否合法

所以做树题第一问通常不是“怎么递归”，而是：

`这个递归函数返回的到底是什么信息？`

一句话记忆：

`树的递归，重点不是往下走，而是往上交什么。`

### 4. DFS 和 BFS 分别是什么？

二叉树常见有两种走法：

1. `DFS` 深度优先搜索  
先一路往下，再回来。递归大多属于 DFS。

2. `BFS` 广度优先搜索  
一层一层往下看，常配合队列使用，也叫层序遍历。

示例树：

```text
    1
   / \
  2   3
 / \
4   5
```

- DFS 可能走成：`1 -> 2 -> 4 -> 回来 -> 5 -> 回来 -> 3`
- BFS 会按层走成：`1 | 2,3 | 4,5`

一般来说：

- 想看“整棵树某条路径”时，常用 DFS
- 想按“第几层”处理时，常用 BFS

### 5. 为什么很多树题适合递归？

因为“整棵树”和“子树”长得很像。

比如求最大深度：

- 整棵树的最大深度
- 左子树的最大深度
- 右子树的最大深度

这三个问题是同一种问题，只是规模变小了，所以很适合递归。

这类题通常都可以写成：

1. 先定义空树怎么办
2. 递归去问左子树
3. 递归去问右子树
4. 用左右结果拼出当前答案

### 6. 二叉树题最常见的出错点

- 没想清楚递归函数返回什么就开始写
- 把前序、中序、后序顺序写混
- 忘记处理空节点 `None`
- 题目其实要“层序遍历”，却硬写成递归深搜
- 以为“返回答案”和“更新全局答案”是一回事

建议你做每道树题前先问自己：

1. 我现在站在哪个节点？
2. 左右子树分别能先帮我算出什么？
3. 这一题更像 DFS 还是 BFS？

## 94. 二叉树的中序遍历


### 题目

原题：[94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

给定一个二叉树的根节点 root ，返回 它的 中序 遍历 。

示例 1：

输入：root = [1,null,2,3]
输出：[1,3,2]

示例 2：

输入：root = []
输出：[]

示例 3：

输入：root = [1]
输出：[1]

提示：

- 树中节点数目在范围 [0, 100] 内

- -100 <= Node.val <= 100

进阶: 递归算法很简单，你可以通过迭代算法完成吗？

### 思路

中序顺序：左、根、右。

### 口诀

`左根右`

### 图解

```text
先递归左，再记录根，再递归右
```

### Python

```python
class Solution:
    def inorderTraversal(self, root):
        res = []
        def dfs(node):
            if not node:
                return
            dfs(node.left)
            res.append(node.val)
            dfs(node.right)
        dfs(root)
        return res
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 104. 二叉树的最大深度


### 题目

原题：[104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)

给定一个二叉树 root ，返回其最大深度。

二叉树的 最大深度 是指从根节点到最远叶子节点的最长路径上的节点数。

示例 1：

输入：root = [3,9,20,null,null,15,7]
输出：3

示例 2：

输入：root = [1,null,2]
输出：2

提示：

- 树中节点的数量在 [0, 104] 区间内。

- -100 <= Node.val <= 100

### 思路

这题是理解“递归函数返回什么”的入门题。

这里 `maxDepth(node)` 的意思不是“遍历一下 node”，  
而是很具体的一句话：

`请你告诉我：以 node 为根的这棵子树，最大深度是多少`

那当前节点能怎么得到答案？

- 先问左子树：你的最大深度是多少
- 再问右子树：你的最大深度是多少
- 谁更深，就选谁
- 再加上当前这个节点自己这一层

所以公式就是：

`当前深度 = 1 + max(左子树深度, 右子树深度)`

### 口诀

`当前深度 = 1 + max(左,右)`

### 图解

```text
例子：
        3
       / \
      9   20
         /  \
        15   7

先看最底层：
9、15、7 都是叶子节点
它们的深度都是 1

再往上：
20 的深度 = 1 + max(1, 1) = 2

最后：
3 的深度 = 1 + max(1, 2) = 3
```

### 背景知识

- 递归函数最重要的是先定义“返回值的含义”
- 空节点 `None` 没有深度，所以返回 `0`
- 叶子节点左右都是空，因此会得到 `1 + max(0, 0) = 1`

### Python

```python
class Solution:
    def maxDepth(self, root):
        # 空树的深度是 0
        if not root:
            return 0

        # 递归求左子树深度
        left_depth = self.maxDepth(root.left)

        # 递归求右子树深度
        right_depth = self.maxDepth(root.right)

        # 当前节点这一层要 +1
        # 再加上左右子树里更深的那一边
        return 1 + max(left_depth, right_depth)
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 226. 翻转二叉树


### 题目

原题：[226. 翻转二叉树](https://leetcode.cn/problems/invert-binary-tree/)

给你一棵二叉树的根节点 root ，翻转这棵二叉树，并返回其根节点。

示例 1：

输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]

示例 2：

输入：root = [2,1,3]
输出：[2,3,1]

示例 3：

输入：root = []
输出：[]

提示：

- 树中节点数目范围在 [0, 100] 内

- -100 <= Node.val <= 100

### 思路

每个节点把左右孩子交换。

### 口诀

`见一个，换一对`

### 图解

```text
left 和 right 对调
```

### Python

```python
class Solution:
    def invertTree(self, root):
        if not root:
            return None
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        return root
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 101. 对称二叉树


### 题目

原题：[101. 对称二叉树](https://leetcode.cn/problems/symmetric-tree/)

给你一个二叉树的根节点 root ， 检查它是否轴对称。

示例 1：

输入：root = [1,2,2,3,4,4,3]
输出：true

示例 2：

输入：root = [1,2,2,null,3,null,3]
输出：false

提示：

- 树中节点数目在范围 [1, 1000] 内

- -100 <= Node.val <= 100

进阶：你可以运用递归和迭代两种方法解决这个问题吗？

### 思路

比较两棵镜像树：左的左 对 右的右，左的右 对 右的左。

### 口诀

`成对镜像比较`

### 图解

```text
外侧比外侧，内侧比内侧
```

### Python

```python
class Solution:
    def isSymmetric(self, root):
        def check(a, b):
            if not a and not b:
                return True
            if not a or not b or a.val != b.val:
                return False
            return check(a.left, b.right) and check(a.right, b.left)
        return check(root.left, root.right) if root else True
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 543. 二叉树的直径


### 题目

原题：[543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)

给你一棵二叉树的根节点，返回该树的 直径 。

二叉树的 直径 是指树中任意两个节点之间最长路径的 长度 。这条路径可能经过也可能不经过根节点 root 。

两节点之间路径的 长度 由它们之间边数表示。

示例 1：

输入：root = [1,2,3,4,5]
输出：3
解释：3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。

示例 2：

输入：root = [1,2]
输出：1

提示：

- 树中节点数目在范围 [1, 104] 内

- -100 <= Node.val <= 100

### 思路

这题很容易把“深度”和“直径”混在一起。

要分清楚两个量：

1. `depth(node)` 返回什么  
   返回：`node` 往下走，最多能走多长。

2. `ans` 记录什么  
   记录：整棵树里目前见过的最长路径长度。

为什么一个节点处可能产生答案？

因为最长路径可能正好“穿过这个节点”：

- 从它左边最深处走上来
- 再从它右边最深处走下去

所以在当前节点这里，路径长度候选就是：

`左深度 + 右深度`

### 口诀

`每个点都试一次左深+右深`

### 图解

```text
例子：
        1
       / \
      2   3
     / \
    4   5

对于节点 2：
左深度 = 1   (到 4)
右深度 = 1   (到 5)
穿过 2 的路径长度 = 2

对于节点 1：
左深度 = 2   (到 4 或 5)
右深度 = 1   (到 3)
穿过 1 的路径长度 = 3

所以答案是 3
对应路径可以是 4 -> 2 -> 1 -> 3
```

### 背景知识

- 这题里的“路径长度”按边数算，不是按节点数算
- 所以 `l + r` 不需要再加 1
- 递归返回给父节点时，只能选左边或右边更长的一条，不能两边都带上去
  因为一条向上的路径不能分叉

### Python

```python
class Solution:
    def diameterOfBinaryTree(self, root):
        # ans 记录整棵树里目前找到的最大直径
        ans = 0

        def depth(node):
            nonlocal ans
            if not node:
                return 0

            # 左子树和右子树各自能向下走多深
            l = depth(node.left)
            r = depth(node.right)

            # 如果最长路径刚好穿过当前节点，
            # 那么长度就是左深度 + 右深度
            ans = max(ans, l + r)

            # 返回给父节点时，只能选一边继续往上接
            return 1 + max(l, r)

        depth(root)
        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 102. 二叉树的层序遍历


### 题目

原题：[102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

给你二叉树的根节点 root ，返回其节点值的 层序遍历 。 （即逐层地，从左到右访问所有节点）。

示例 1：

输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]

示例 2：

输入：root = [1]
输出：[[1]]

示例 3：

输入：root = []
输出：[]

提示：

- 树中节点数目在范围 [0, 2000] 内

- -1000 <= Node.val <= 1000

### 思路

BFS，一层一层弹队列。

### 口诀

`队列按层推进`

### 图解

```text
当前层有几个，就弹几个
```

### Python

```python
from collections import deque

class Solution:
    def levelOrder(self, root):
        if not root:
            return []
        q = deque([root])
        res = []
        while q:
            level = []
            for _ in range(len(q)):
                node = q.popleft()
                level.append(node.val)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            res.append(level)
        return res
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 108. 将有序数组转换为二叉搜索树


### 题目

原题：[108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

给你一个整数数组 nums ，其中元素已经按 升序 排列，请你将其转换为一棵 平衡 二叉搜索树。

示例 1：

输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：[0,-10,5,null,-3,null,9] 也将被视为正确答案：

示例 2：

输入：nums = [1,3]
输出：[3,1]
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。

提示：

- 1 <= nums.length <= 104

- -104 <= nums[i] <= 104

- nums 按 严格递增 顺序排列

### 思路

这题先别急着想代码，先想 BST 的特点：

- 左边都比根小
- 右边都比根大

数组本来就是升序的，所以很适合拿中间值当根：

- 中间左边那部分，自然都比根小
- 中间右边那部分，自然都比根大

而且拿中间值还有一个额外好处：

`左右两边数量比较接近，树就更平衡`

所以整题就是一个“二分建树”的过程。

### 口诀

`中间做根，左右递归`

### 图解

```text
nums = [-10, -3, 0, 5, 9]

先取中间值 0 做根：
        0

左半边 [-10, -3] 继续建左子树
右半边 [5, 9] 继续建右子树

左半边再取中间：
      0
     / \
   -10  5
      \   \
      -3   9

形状不一定唯一，
但核心思想都是“中间做根”
```

### 背景知识

- BST：二叉搜索树
- 平衡：左右子树高度差尽量小
- `build(left, right)` 的含义是：
  “请你把 `nums[left:right+1]` 这一段建成一棵树”

### Python

```python
class Solution:
    def sortedArrayToBST(self, nums):
        def build(left, right):
            # 区间空了，说明这里没有节点
            if left > right:
                return None

            # 取中间元素做根节点
            mid = (left + right) // 2
            root = TreeNode(nums[mid])

            # 左半边建左子树
            root.left = build(left, mid - 1)

            # 右半边建右子树
            root.right = build(mid + 1, right)
            return root
        return build(0, len(nums) - 1)
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(log n)`

## 98. 验证二叉搜索树


### 题目

原题：[98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)

给你一个二叉树的根节点 root ，判断其是否是一个有效的二叉搜索树。

有效 二叉搜索树定义如下：

- 节点的左子树只包含 严格小于 当前节点的数。

- 节点的右子树只包含 严格大于 当前节点的数。

- 所有左子树和右子树自身必须也是二叉搜索树。

示例 1：

输入：root = [2,1,3]
输出：true

示例 2：

输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5 ，但是右子节点的值是 4 。

提示：

- 树中节点数目范围在[1, 104] 内

- -231 <= Node.val <= 231 - 1

### 思路

这题最容易掉进去的坑是：

只检查“当前节点和左右孩子”的大小关系，这样是不够的。

比如这棵树：

```text
    5
   / \
  1   4
     / \
    3   6
```

虽然 `4 < 6`、`3 < 4` 看起来都没问题，  
但 `4` 在根节点 `5` 的右子树里，它本来就必须大于 `5`，结果它小了，所以这不是 BST。

最好记的做法是：

`BST 的中序遍历结果，必须是严格递增的`

因为中序顺序是：左、根、右。  
对于 BST 来说，这正好会从小到大访问所有值。

### 口诀

`中序必须严格递增`

### 图解

```text
如果一棵树是合法 BST，
中序遍历出来会像这样：
1, 2, 3, 5, 7, 9

必须一直满足：
前一个值 < 当前值

只要出现：
前一个值 >= 当前值
就说明不是 BST
```

### 背景知识

- 中序遍历顺序：左子树 -> 根节点 -> 右子树
- `prev` 用来记录“刚刚访问过的上一个值”
- 这里要求“严格递增”，所以相等也不行

### Python

```python
class Solution:
    def isValidBST(self, root):
        # prev 记录中序遍历时，上一个访问到的值
        prev = None

        def dfs(node):
            nonlocal prev
            if not node:
                return True

            # 先检查左子树
            if not dfs(node.left):
                return False

            # 中序遍历访问当前节点时，
            # 当前值必须比上一个值更大
            if prev is not None and node.val <= prev:
                return False

            # 更新上一个值
            prev = node.val

            # 再检查右子树
            return dfs(node.right)

        return dfs(root)
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 230. 二叉搜索树中第 K 小的元素


### 题目

原题：[230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)

给定一个二叉搜索树的根节点 root ，和一个整数 k ，请你设计一个算法查找其中第 k 小的元素（k 从 1 开始计数）。

示例 1：

输入：root = [3,1,4,null,2], k = 1
输出：1

示例 2：

输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3

提示：

- 树中的节点数为 n 。

- 1 <= k <= n <= 104

- 0 <= Node.val <= 104

进阶：如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 k 小的值，你将如何优化算法？

### 思路

这题几乎就是上一题的直接应用。

既然 BST 的中序遍历结果是升序，  
那第 `k` 个被访问到的节点，就是第 `k` 小的值。

所以核心不是“怎么排序”，而是：

`按中序遍历顺序，一个一个数过去`

数到第 `k` 个时立刻停下。

### 口诀

`BST 中序就是有序数组`

### 图解

```text
例子：
        5
       / \
      3   6
     / \
    2   4
   /
  1

中序遍历顺序是：
1, 2, 3, 4, 5, 6

如果 k = 3
数到第 3 个，就是 3
```

### 背景知识

- 这份代码用的是“迭代版中序遍历”
- `stack` 用来模拟递归调用栈
- `while root: stack.append(root); root = root.left`
  这段的意思是：一路先把左边走到底

### Python

```python
class Solution:
    def kthSmallest(self, root, k):
        stack = []
        while True:
            # 一路往左走，把沿途节点压栈
            # 这样栈顶就是“当前最小、还没访问过”的节点
            while root:
                stack.append(root)
                root = root.left

            # 弹出一个节点，等价于“访问这个节点”
            root = stack.pop()
            k -= 1

            # 数到第 k 个，直接返回
            if k == 0:
                return root.val

            # 然后去处理它的右子树
            root = root.right
```

### 复杂度

- 时间复杂度：`O(h+k)`
- 空间复杂度：`O(h)`

给定一个二叉树的 根节点 root，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

解释：

示例 2：

输入：root = [1,2,3,4,null,null,null,5]

输出：[1,3,4,5]

解释：

示例 3：

输入：root = [1,null,3]

输出：[1,3]

示例 4：

输入：root = []

输出：[]

提示:

- 二叉树的节点个数的范围是 [0,100]

- -100 <= Node.val <= 100

### 思路

层序遍历，每层最后一个节点就是右视图。

### 口诀

`每层最后一个`

### 图解

```text
队列一层一层弹，记最后弹出的值
```

### Python

```python
from collections import deque

class Solution:
    def rightSideView(self, root):
        if not root:
            return []
        q = deque([root])
        res = []
        while q:
            size = len(q)
            for i in range(size):
                node = q.popleft()
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
                if i == size - 1:
                    pass
            res.append(node.val)
        return res
```

- 时间复杂度：`O(n)`

输入：root = [1,2,5,3,4,null,6]

示例 2：

示例 3：

输入：root = [0]
输出：[0]

提示：

- 树中结点数在范围 [0, 2000] 内

- -100 <= Node.val <= 100

进阶：你可以使用原地算法（O(1) 额外空间）展开这棵树吗？

### 思路

后序思路：先展平左右，再把左链挂到右边。

### 口诀

`先展平，再重接`

```text
root.right 接左链，左链尾巴接原右链
```

```python
class Solution:
    def flatten(self, root):
        cur = root
        while cur:
            if cur.left:
                pre = cur.left
                while pre.right:

                cur.right = cur.left
                cur.left = None
            cur = cur.right
```

- 时间复杂度：`O(n)`

## 105. 从前序与中序遍历序列构造二叉树


### 题目

原题：[105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

给定两个整数数组 preorder 和 inorder ，其中 preorder 是二叉树的先序遍历， inorder 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

示例 1:

输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]

示例 2:

输入: preorder = [-1], inorder = [-1]
输出: [-1]

提示:

- 1 <= preorder.length <= 3000

- inorder.length == preorder.length

- -3000 <= preorder[i], inorder[i] <= 3000

- preorder 和 inorder 均 无重复 元素

- inorder 均出现在 preorder

- preorder 保证 为二叉树的前序遍历序列

- inorder 保证 为二叉树的中序遍历序列

### 思路

这题最重要的是先把两种遍历的作用分开：

- 前序：`根 -> 左 -> 右`
  所以前序数组的第一个值，一定是当前子树的根。

- 中序：`左 -> 根 -> 右`
  所以只要在中序数组里找到这个根，就能知道：
  - 左边整段是左子树
  - 右边整段是右子树

接下来就是递归重复这件事。

你可以把它想成：

`前序负责告诉你谁是根，中序负责告诉你左右边界`

### 口诀

`前序定根，中序分左右`

### 图解

```text
例子：
preorder = [3, 9, 20, 15, 7]
inorder  = [9, 3, 15, 20, 7]

第 1 步：
前序第一个 3 是整棵树的根

在中序里找到 3：
[9] 3 [15,20,7]

说明：
左子树只有 [9]
右子树是 [15,20,7]

第 2 步：
继续递归建左右子树
```

### 背景知识

- 递归函数 `build(pre_l, pre_r, in_l, in_r)` 的含义是：
  “请根据前序的这一段和中序的这一段，建出对应子树”
- `pos` 哈希表用于快速查某个值在中序数组中的位置
- `left_size` 表示左子树有多少个节点

### Python

```python
class Solution:
    def buildTree(self, preorder, inorder):
        # 记录每个值在 inorder 中的位置，后面 O(1) 查找
        pos = {v: i for i, v in enumerate(inorder)}

        def build(pre_l, pre_r, in_l, in_r):
            # 区间空了，说明没有子树
            if pre_l > pre_r:
                return None

            # 前序遍历这一段的第一个值，就是当前子树的根
            root_val = preorder[pre_l]

            # 在中序里找到根的位置
            k = pos[root_val]

            # 中序里根左边有多少个节点，左子树就有多少个节点
            left_size = k - in_l
            root = TreeNode(root_val)

            # 递归构建左子树
            root.left = build(pre_l + 1, pre_l + left_size, in_l, k - 1)

            # 递归构建右子树
            root.right = build(pre_l + left_size + 1, pre_r, k + 1, in_r)
            return root
        return build(0, len(preorder) - 1, 0, len(inorder) - 1)
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

## 437. 路径总和 III


### 题目

原题：[437. 路径总和 III](https://leetcode.cn/problems/path-sum-iii/)

给定一个二叉树的根节点 root ，和一个整数 targetSum ，求该二叉树里节点值之和等于 targetSum 的 路径 的数目。

路径 不需要从根节点开始，也不需要在叶子节点结束，但是路径方向必须是向下的（只能从父节点到子节点）。

示例 1：

输入：root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出：3
解释：和等于 8 的路径有 3 条，如图所示。

示例 2：

输入：root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
输出：3

提示:

- 二叉树的节点个数的范围是 [0,1000]

- -109 <= Node.val <= 109

- -1000 <= targetSum <= 1000

### 思路

前缀和 + DFS。到当前点前缀和是 `cur`，若之前出现过 `cur-target`，说明有路径和为 target。

### 口诀

`树上也能做前缀和`

### 图解

```text
当前前缀和减目标值，去找历史前缀和
```

### Python

```python
from collections import defaultdict

class Solution:
    def pathSum(self, root, targetSum):
        count = defaultdict(int)
        count[0] = 1
        ans = 0
        def dfs(node, cur):
            nonlocal ans
            if not node:
                return
            cur += node.val
            ans += count[cur - targetSum]
            count[cur] += 1
            dfs(node.left, cur)
            dfs(node.right, cur)
            count[cur] -= 1
        dfs(root, 0)
        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)` 到 `O(n)`

## 236. 二叉树的最近公共祖先


### 题目

原题：[236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

百度百科中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（一个节点也可以是它自己的祖先）。”

示例 1：

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3 。

示例 2：

输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5 。因为根据定义最近公共祖先节点可以为节点本身。

示例 3：

输入：root = [1,2], p = 1, q = 2
输出：1

提示：

- 树中节点数目在范围 [2, 105] 内。

- -109 <= Node.val <= 109

- 所有 Node.val 互不相同 。

- p != q

- p 和 q 均存在于给定的二叉树中。

### 思路

这题最容易卡住的点是：

`递归函数返回的到底是什么？`

这里你要把它定义成：

`lowestCommonAncestor(root, p, q)` 返回：在以 root 为根的这棵子树里，p 和 q 的最近公共祖先；如果只找到其中一个，就先把那个节点返回上去；如果都没找到，就返回 None`

这样就好理解了：

- 如果当前节点就是 `p` 或 `q`，直接返回自己
- 去左子树找一次
- 去右子树找一次

然后分情况：

- 左边有、右边也有  
  说明 `p` 和 `q` 分别在两侧，当前节点就是最近公共祖先

- 只有一边有  
  说明答案还在那一边，继续往上返回

### 口诀

`左右都找到，当前就是答案`

### 图解

```text
左有右有 -> 当前
只有一边有 -> 返回那边

例子：
        3
       / \
      5   1
         / \
        0   8

如果找 5 和 1：
左边返回 5
右边返回 1
所以当前节点 3 就是答案

如果找 5 和 4（4 在 5 的子树里）：
一路返回时，
节点 5 会先命中自己
另一边又能找到 4
所以答案是 5
```

### 背景知识

- `None` 表示这一整棵子树里没找到
- 这类题不要死记“先左后右”，要先定义清楚返回值语义
- “一个节点也可以是它自己的祖先”，这是题目定义的一部分

### Python

```python
class Solution:
    def lowestCommonAncestor(self, root, p, q):
        # 递归终止：
        # 1. 空节点，没找到
        # 2. 正好遇到 p 或 q，先把它自己返回上去
        if not root or root == p or root == q:
            return root

        # 去左右子树里继续找
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)

        # 左右都找到了，说明当前节点就是分叉点，也就是 LCA
        if left and right:
            return root

        # 否则哪边找到了就返回哪边
        return left or right
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`

## 124. 二叉树中的最大路径和


### 题目

原题：[124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

二叉树中的 路径 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 至多出现一次 。该路径 至少包含一个 节点，且不一定经过根节点。

路径和 是路径中各节点值的总和。

给你一个二叉树的根节点 root ，返回其 最大路径和 。

示例 1：

输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6

示例 2：

输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42

提示：

- 树中节点数目范围是 [1, 3 * 104]

- -1000 <= Node.val <= 1000

### 思路

这题是树题里最抽象的一类，因为它同时有两个目标：

1. 返回给父节点什么
2. 整棵树的最终答案是什么

一定要把这两件事分开。

对于某个节点 `node`：

- 如果它要继续往上接到父节点，那么父节点只能选它左边或右边的一条路
  不能左右两边都带上去，不然路径会分叉

所以“返回给父节点”的值应该是：

`node.val + max(左贡献, 右贡献, 0)`

为什么要和 `0` 比？

因为如果某一边贡献是负数，还不如不要那一边。

但“最终答案”不一样。  
在当前节点这里，可以把左边和右边都接上，形成一整条完整路径：

`左贡献 + node.val + 右贡献`

这个值要拿来更新全局最大答案。

### 口诀

`返回单链，更新整条路径`

### 图解

```text
例子：
       -10
       /  \
      9    20
          /  \
         15   7

看节点 20：
左贡献 = 15
右贡献 = 7

1. 返回给父节点的值：
20 + max(15, 7) = 35
因为往上只能带一条链

2. 作为当前节点的完整路径值：
15 + 20 + 7 = 42
这个可以用来更新答案

所以最终答案是 42
```

### 背景知识

- “贡献”可以理解成：这个子树能给父节点带来的最大收益
- 负贡献直接舍弃，所以用 `max(..., 0)`
- `ans` 是全局变量，用来记住整棵树里见过的最大路径和

### Python

```python
class Solution:
    def maxPathSum(self, root):
        # ans 保存整棵树中的最大路径和
        ans = float('-inf')

        def dfs(node):
            nonlocal ans
            if not node:
                return 0

            # 左右子树能贡献给当前节点的最大值
            # 如果是负数，宁可不要，所以和 0 比
            l = max(dfs(node.left), 0)
            r = max(dfs(node.right), 0)

            # 把当前节点当作“路径最高点”时，
            # 可以同时使用左边和右边
            ans = max(ans, node.val + l + r)

            # 但返回给父节点时，只能带一条链往上走
            return node.val + max(l, r)

        dfs(root)
        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`
