# Hot100 滑动窗口题解

只整理 LeetCode Hot 100 里属于 `滑动窗口` 的题。

核心：`右边扩张拿新字符，左边收缩去掉多余字符。`

## 一、滑动窗口前置知识：它专治哪类题

滑动窗口常用来处理“连续的一段”：

- 最长子串
- 最短子数组
- 满足某种条件的一段区间

你可以把它想成一个可伸缩的小框：

- 右边往前走，把新元素装进框里
- 如果框里不合法了，就移动左边，把多余元素扔出去

什么时候该想到滑动窗口：

- 题目里出现 `子串`、`子数组`、`连续`
- 你不是要枚举所有区间，而是想一边走一边维护当前这段区间

要特别注意：

- 先分清楚“什么时候扩张”和“什么时候收缩”
- 窗口里通常要配一个辅助结构，比如 `set`、`dict`、计数器
- 不是所有区间题都能用滑动窗口；如果有负数、条件不单调，有时就不适合

速记一句话：

`右边负责拿新东西，左边负责把窗口修回合法。`

## 3. 无重复字符的最长子串


### 题目

原题：[3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。

示例 1:

输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

示例 2:

输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。

示例 3:

输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。

提示：

- 0 <= s.length <= 5 * 104

- s 由英文字母、数字、符号和空格组成

### 思路

用集合维护当前窗口中的字符。右指针扩张，如果出现重复，就一直移动左指针直到窗口重新合法。

### 口诀

`右边加，重复了就左边缩`

### 图解

```text
窗口里不能有重复
一重复 -> 左边不断弹出
```

### Python

```python
class Solution:
    def lengthOfLongestSubstring(self, s):
        seen = set()
        left = 0
        ans = 0
        for right, ch in enumerate(s):
            while ch in seen:
                seen.remove(s[left])
                left += 1
            seen.add(ch)
            ans = max(ans, right - left + 1)
        return ans
```

### 复杂度

- 时间复杂度：`O(n)`
- 空间复杂度：`O(k)`，`k` 是字符种类数

## 438. 找到字符串中所有字母异位词


### 题目

原题：[438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

给定两个字符串 s 和 p，找到 s 中所有 p 的 异位词 的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

示例 1:

输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

示例 2:

输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。

提示:

- 1 <= s.length, p.length <= 3 * 104

- s 和 p 仅包含小写字母

### 思路

窗口长度固定为 `len(p)`。维护窗口里每个字符的出现次数，和目标串的计数相同就记录左边界。

### 口诀

`定长窗口比计数`

### 图解

```text
窗口长度固定
每次右边进一个，左边出一个
比较计数是否相同
```

### Python

```python
from collections import Counter

class Solution:
    def findAnagrams(self, s, p):
        need = Counter(p)
        window = Counter()
        res = []
        left = 0
        for right, ch in enumerate(s):
            window[ch] += 1
            if right - left + 1 > len(p):
                window[s[left]] -= 1
                if window[s[left]] == 0:
                    del window[s[left]]
                left += 1
            if right - left + 1 == len(p) and window == need:
                res.append(left)
        return res
```

### 复杂度

- 时间复杂度：`O(n)`，字符集固定时比较可视作常数
- 空间复杂度：`O(1)`
